化学

把器材拖到台面上（点一下也能直接放上来），再把药瓶拖到器材上就是加试剂； 点「导管」进连接模式，再点两个接口点就把装置接起来，出气时能看到气泡沿导管过去； 器材下面的「加热 / 倒掉 / 倾斜」按需要点。全部按随包离线规则表判，查不到会直接说「资料未收录」。

器材右上角的「×」可以单独拿走一件；「倒掉」只倒掉里面的试剂。 检查装置只判摆法（有没有倾斜、有没有铁架台、有没有接导管），反应对不对看下面对话框的结果
恒容密闭反应釜 恒容：气体不外逸，加压=按该压强重新配料（合成氨加压平衡右移）；不设压强时另充惰性气体只升总压、平衡不移动
