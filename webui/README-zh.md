# Study7Agent WebUI（现代化交互界面）

面向 Windows 7 x64 离线内网的本地 Web 控制台：**零安装、零依赖、零构建**，
只使用随包分发的 `python\python.exe`（Python 3.8.10）与同目录的 `agent.exe`。当前版本 **0.5.0**。

老师拿到的是一个**单文件 exe**（1.1.0 起）：

```bat
python\python.exe scripts\make-release.py
```

产物（版本号取自 `webui\core.py` 的 `VERSION`）：

| 文件 | 给谁 | 里面有密钥吗 |
| --- | --- | --- |
| `dist\study7agent-<版本>.exe` | 对外分发，**就这一个文件** | 没有，一个 `sk-` 串都没有 |
| `dist\study7agent-<版本>-deepseek.zip` | 只给指定的那台机器 | 有，且只在 `config\agent.json` 一处 |

exe 由 `scripts\make-exe.py` 打：程序树（`python\`、`webui\`、内置 Chromium 109）打成 tar.gz
追加在 exe 尾部，启动器首次运行时解到「程序目录」或 `%ProgramData%\Study7Agent`（**不解到
用户目录下**，那儿内核起不来，见 `docs\embedded-browser.md`），第二次启动直接用。
"发哪些文件"的规则沿用 `scripts\make-package.py` 里那份，不重复实现：排除
`config\agent.json`（含 API Key）、`config\webui.json`、`webui\data\` 会话记录、`logs\` 与源码镜像，
并带上 `config\agent.example.json` 供首次启动自动复制。

两个变体的 exe **字节完全相同**，差别只在旁边那份 `config\agent.json`。
**注意：谁拿到带密钥的那个 zip，谁就能用你的额度**——不要发到群里、网盘或公共共享盘；
一旦外泄，去 `platform.deepseek.com` 把它删掉重新生成一把。对外分发请用那个干净 exe。

```bat
:: 解压后直接双击或用命令行启动
start-webui.cmd
```

启动后会自动打开浏览器（默认 <http://127.0.0.1:8770>），控制台会打印模型、接口、工作区与地址。

**启动器图标**：首次运行 `start-webui.cmd` 会自动做两件事（失败也不影响启动）：

1. 在桌面创建带图标的快捷方式「Study7Agent」（图标取同目录的 `agent.ico`）；
2. 给解压目录本身设置文件夹图标（`desktop.ini` + `IconResource`）。

`agent.ico` 含 7 个尺寸（16/24/32/48/64/128/256），源图 `agent-icon.png` 取自
[Fluent Emoji](https://github.com/microsoft/fluentui-emoji)（MIT 许可，毕业帽）。
想换成学校自己的图标：把新 PNG 命名为 `agent-icon.png`，然后运行

```bat
python\python.exe scripts\make-icon.py agent-icon.png agent.ico
```

- 可选参数：`start-webui.cmd --port 8899 --no-open --verbose`
- 停止服务：在控制台窗口按 `Ctrl+C`

### 1.1 步骤折叠栏（思考 + 工具调用）

参考 DeepSeek Harness 的 dsh-turn-fold：**一次提问产生的思考与连续工具调用合并成一个折叠栏**，
最终回答严格显示在折叠栏**之外**。

| 状态 | 表现 |
| --- | --- |
| 生成中 | 自动展开，标题显示「思考中…」，左侧是旋转的加载圈；调用工具时标题变成「调用 read_file…」 |
| 生成结束 | 自动折叠，标题变成「思考过程」，右侧显示「N 步 · 12.4s」 |
| 用户手动点过 | 展开/折叠完全听用户的，**不再自动折叠**（手动展开的不会被自动收起） |
| 多轮工具 | 每一轮之间用「第 N 轮」分隔，所有轮次的思考与工具都在同一个折叠栏里 |
| 中间轮次的文字 | 属于回答本身，**按顺序接着往下写**，不会被搬走、也不会把消息切成好几段 |

### 1.2 推理等级（像 DeepSeek Harness 一样选）

顶栏模型选择器旁边就是推理等级，**按会话记住**（切回这个会话还是它）：

| 选项 | 发给接口的 `reasoning_effort` | 适合什么 |
| --- | --- | --- |
| 默认 | 不传这个参数 | 沿用接口/模型自己的行为，最稳妥 |
| 最省 minimal | `minimal` | 改写、翻译、格式转换这类有明确答案的活，最快最省 |
| 低 low | `low` | 日常问答、简单整理 |
| 中 medium | `medium` | 出题、写教案、分析成绩这类要想一想的活 |
| 高 high | `high` | 整套课件、跨多个文件核对这种复杂多步任务（更慢、思考 token 更多） |

* 设置里可以定**默认等级**（新会话的起点），顶栏随时可以按会话临时改；子代理沿用主代理选的等级。
* 右下角「本次运行」会显示**这一轮实际用的等级**（接口拒绝参数降级后显示的就是降级后的结果）。
* 接口不认这个参数（返回 400 提到 `reasoning_effort`/`reasoning`/`thinking`）时会**自动去掉参数重试一次**，
  并在对话里如实提示“当前接口不支持 reasoning_effort 参数，已按‘默认’推理等级重试”，不会整轮失败。

### 1.3 一条连续的消息（不会断成几截）

一次提问对应**一条**助手消息：折叠栏里是过程，折叠栏下面是一整条正文。

* 工具调用**不会**清空或截断正文——模型调用工具前说的话、工具跑完接着说的话，都按顺序落在同一条正文里；
* 折叠栏只在整轮运行**真正结束**时才收尾，中间不会闪一下“结束”再重新开始；
* 模型输出被长度上限截断、或者一个字都没写时，服务端会**自动接着写**（最多 3 次），
  并在消息里留一条说明（“回答被长度上限截断，已自动继续写（第 1 次）。”），不会静默停住；
* 运行被熔断、工具轮次用尽、长度上限连撞多次或用户手动停止时，消息底部出现**一键「继续生成」**按钮，
  点一下就接着写，不用自己打字；这个“没写完”的标记会**存进会话**，刷新页面/换电脑重新打开时按钮还在；
* **不会“干到一半突然罢工”**（这是真机反馈修出来的一组问题）：
  * 工具轮次上限默认 **40**（原来 8 轮，画个正方体几笔就用完了）。用尽时会明确说明
    “这一轮的工具调用没有执行、任务还没做完”，并留下「继续生成」——不再只丢下一句半截话就结束；
  * 用尽后请模型收尾时会**明确要求只用文字总结**（不带 tools），避免它把工具调用“写”在正文里
    （界面上看着就是一大段工具信息然后对话终止）；
  * 万一模型还是把工具调用写成文字，会自动**提醒它改用原生调用重试**（最多 2 次），
    仍不成就明确报错并保留「继续生成」，而不是把那段文字当成最终答复；
  * 熔断不再误伤：连续调用**只读幂等**工具（截屏、列窗口、读文件、读剪贴板）是正常操作
    （画一笔看一眼白板），不算“打转”；短回答（“好的”“继续”）也不会被当成重复而熔断。
* 用户再次提问后，上一轮的「继续生成」自动消失。

**思考内容有两种来源，都兼容**：

1. 模型原生输出 `reasoning_content`（DeepSeek 等）→ 直接取该字段；
2. 模型把思考写在 `<think>…</think>` / `<thinking>` / `<reasoning>` / `<thought>` 里 → 服务端流式解析标签。

解析在服务端完成（`core.ThinkSplitter`），所以跨数据块的标签（`<thi` + `nk>`）、没闭合的标签、
多余的结束标签、正文里出现的小写小于号（如 `a < b`）都能正确处理；前端只消费 `reasoning` / `content`
两种事件。回答里**永远不会残留标签**，历史消息也不会把思考回传给模型。

## 2. 为 DeepSeek 做的适配

1. **原生 Function Calling**：用标准 `tools` / `tool_calls` 协议取代 CLI 的 ```agent-action 文本约定，
   模型不再需要“背诵”JSON 格式；流式工具参数会被完整拼接后执行。
2. **思考过程（reasoning_content）**：单独解析并展示，且**不会**把思考内容回传下一轮
   （DeepSeek 要求历史消息中不要携带 `reasoning_content`）。
3. **上下文缓存计费可视**：读取 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens` /
   `prompt_tokens_details.cached_tokens`，界面实时显示命中率与按命中价/未命中价分别计算的费用。
4. **缓存友好**：系统提示词保持稳定前缀（不注入时间戳等易变内容），工具定义顺序固定，
   提高 DeepSeek 前缀缓存的命中率。
5. **模型列表与余额**：设置页可一键从接口拉取真实模型列表（`GET /models`），
   并可通过 `/api/balance` 查询账户余额（DeepSeek 支持时）。
6. **多轮工具循环**：回合上限可配（默认 8），达到上限会提示而不是静默截断；
   工具调用与结果严格配对，历史裁剪时不会破坏 `tool_calls`/`tool` 结构。
7. **识图**：用户直接发的图片走多模态 messages；模型自己发现的本地图片走 `view_image`
   工具注入，两条路径都实测可用（见 3.2 节）。
7. **兼容不同网关**：`base_url` 支持裸域名（`https://api.deepseek.com`）、`/v1` 结尾或完整
   `/chat/completions` 三种写法，服务端会自动补全；万一路径不对（404/405），
   会再退一步尝试 `/v1/chat/completions`，不会因为少写一段路径就整体报错。
   设置界面会实时显示“实际请求地址”，保存的始终是你手写的原始地址。

| `send_email` | 发邮件（QQ 邮箱/163/学校邮箱），可带附件 |
| `notify_webhook` | 推送到企业微信 / 钉钉 / 飞书群机器人 |
| `send_qq_message` | 用本机 QQ 发消息（模拟操作，发完自动截图供核对） |
| `pick_students` / `class_timer` / `show_on_screen` / `mistake_book` / `score_stats` | 课堂互动：抽学号、计时、投屏、错题本、成绩统计 |
| `web_search` / `run_subagent` | 联网搜索、派子代理并行干活 |

### 3.0 音视频与课件媒体（"视频放不了"专用）

教室一体机上最常见、最难自查的一类故障是"课件里的视频播不出来"。这条链路有三个独立的坑，
本工具把三个都查一遍，并且**每一步都给老师能自己对得上的解释**：

| 环节 | 工具 | 能查出什么 |
| --- | --- | --- |
| 文件本身 | `inspect_media` | 编码是不是 Win7 放不了的（HEVC/AV1/Xvid）、文件是否被截断（缺 moov 索引）、是不是 0 字节、是不是根本不是视频 |
| 怎么插进课件的 | `diagnose_pptx` | 每页引用了哪些媒体、是**内嵌**还是**外链**（外链换个文件夹/换台电脑就播不了）、有没有缺失的媒体部件、有没有嵌入字体 |
| 怎么修 | `extract_media` + `replace_media` | 取出原视频 → 用格式工厂/剪映转成 MP4(H.264)+AAC → 放回原位置（PPT 里不用重新插入） |

典型排查顺序：

```text
diagnose_pptx(path="D:\课件\第3课.pptx")     ← 先看是外链还是编码问题
inspect_media(path="D:\课件\media\media1.mp4")  ← 再看文件本身
```

引擎只读文件头（不依赖 ffmpeg、不联网），所以又快又不会动原文件；本机装了 ffmpeg 时，
报错信息里会直接给出转码命令。**注意**：本工具能判断兼容性，但不做转码——
转码需要 ffmpeg 或格式工厂这类外部程序，学校机器上通常没有。

### 3.1 教学场景：课件 / 教案 / 试卷 / 成绩表

这台机器通常是教室里的教学一体机，最常见的四类产出都能直接生成成可编辑的 Office 文件
（进程内生成标准 OOXML，不需要装 Office，生成的 `.pptx` 已用 PowerPoint 2016 实测可直接打开编辑）：

| 需求 | 生成格式 | 说明 |
| --- | --- | --- |
| 课件 | `.pptx` | 16:9，标题 36pt / 正文 28pt，表格带蓝色表头；面向教室大屏可读 |
| 教案 / 通知 / 试卷 | `.docx` | 支持 `#` 标题层级、`-` 列表、Markdown 表格、`**加粗**`、`等宽` |
| 成绩表 / 统计表 | `.xlsx` | 首行自动加粗、冻结、列宽按内容自适应 |
| 讲稿备注 | `.md` | 大纲里的 `> ` 行会另存为「课件名.讲稿.md」，方便打印或课上照读 |

**课件大纲写法**（`write_file` 的 content）：

```text
# 分数的初步认识          ← 一个 # 就是一张幻灯片
## 三年级数学              ← ## 是页内小标题
- 每页要点不超过 3 行      ← - 项目符号（缩进 2 空格降一级）
1. 第一步                 ← 1. 自动编号
| 分法 | 是否平均分 |      ← 页内表格（Markdown 表格）
| --- | --- |
| 分成 2 份，一样大 | 是 |
> 讲解话术写在这里          ← 演讲者备注，另存讲稿文件
---                        ← 强制分页
```

**沿用学校统一模板**：`write_file` 支持可选的 `template` 参数，填模板 `.pptx` 的绝对路径，
新页面会追加到模板里并沿用模板的主题配色、母版与页面尺寸：

```text
write_file(path="D:\课件\分数的初步认识.pptx", content="...", template="D:\模板\校模板.pptx")
```

**改旧稿**：先用 `read_file` 读回旧课件的文字大纲，改完再 `write_file` 覆盖（自动快照可回滚），
所以"把上节课的课件改成复习课"这类需求是可做的。

### 3.2 识图（图片输入）

`deepseek-flash` 支持图片输入，可以看图作答。已实测：给它一张学生随堂练习的照片，
它能读出标题、姓名栏、每一道题、红笔标注的学生答案，并判断对错。

**三种添加图片的方式**（一体机上最常用的是第一种）：

| 方式 | 操作 |
| --- | --- |
| 粘贴截图 | 用系统截图（Win+Shift+S 或 QQ/微信截图）后在输入框 `Ctrl+V`，直接变成待发送图片 |
| 点选图片 | 点「图片」按钮，在弹窗里点盘符 / 桌面 / 文档 / 工作区逐层点选，**不用输入路径** |
| 上传图片 | 选择器里的「从电脑选择文件」用系统文件对话框选图（内容会上传到工作区，浏览器拿不到真实路径） |

限制与提示：

- 支持 `png/jpg/jpeg/gif/webp/bmp`，单张不超过 8MB，一条消息最多 6 张。
- 图片按图片 token 计费（一张 900×640 的练习照片约 500-900 token），
  历史里只保留**最近两轮**的图片，更早的图片会自动省略并提示，避免反复计费。
- **模型自己看图**：`list_dir` 里发现的照片可以让模型用 `view_image` 打开；
  该工具会把图片注入下一轮请求，所以模型是"真的看见"，不是猜文件名。
- **不是所有模型都支持图片**：`deepseek-v4-pro` 会回复"无法查看这张图片"。
  检测到这种回复时，界面会提示切换到 `deepseek-flash`。
- 图片里看不清、被裁掉的内容，模型应当明说；教学上建议重拍或补拍局部，而不是让它猜。

教学上的典型用法：

```text
（粘贴一张学生作业照片）这是学生第 3 单元的随堂练习，帮我批改，并把错题整理成讲评课件
（粘贴一张课本页面截图）按这一页的知识点出 10 道同难度练习题，含答案与解析
（拖入一张单元成绩表截图）整理成 .xlsx，统计平均分和分数段
```

**内置教学技能**：`skills\` 下新增了 `courseware`（课件规范：一课一件、大字号、少字多图）、
`lesson-plan`（教案栏目与三维目标写法）、`quiz`（题型分布、难度梯度、答案解析）、
`grade-analysis`（及格率/优秀率/分数段/错因归类）。输入里提到相关词语时会自动带上，
也可以用 `@skill:courseware` 显式引用。

## 3.3 工作区（AI 产出的默认位置）

- 默认工作区是解压目录下的 `workspace\`，服务启动时自动创建。
- **AI 新建的文件默认写在工作区里**：只说一个文件名（例如 `分数的初步认识.pptx`）就写进工作区；
  只有你明确给出别的路径（`D:\共享\...`）时才会写到那里。系统提示词里已经写清这条规则。
- 顶部「工作区」按钮可以做三件事：
  1. **选择文件夹**：用图形化选择器把工作区换到桌面、D 盘或共享目录；
  2. **在资源管理器中打开**：直接弹出文件夹窗口；
  3. **查看工作区里的文件**：列出生成的文件，点「打开」用系统默认程序打开（课件会直接用 WPS/PowerPoint 打开），
     出于安全考虑 `.exe/.bat/.cmd/.ps1` 等可执行文件不允许从界面直接运行。
- 上传的图片/文件也统一放在 `工作区\.webui-uploads\`，所以模型之后还能继续读取它们。
- 工作区保存在 `config\webui.json` 的 `workspace_root`，也可以在设置里修改。

## 3.4 技能（Skills）

技能是写给 AI 的固定要求，放在 `skills\<名称>\SKILL.md`。界面上的「技能」按钮提供完整管理：

- **勾选启用**：勾上的技能，本会话每次提问都会带到模型前面（按会话保存，不同班级/学科可以配不同技能）。
  输入框上方的技能小圆点就是快捷开关，点亮表示已启用。
- **查看 / 修改 / 删除**：点每条右侧的放大镜或铅笔可以把内容读进下面的表单修改；垃圾桶删除该技能目录。
- **新建**：填「技能名称 + 一句话说明 + 具体规则」保存即可，立刻生效，不需要重启。
- **自动匹配**：没勾选的技能也会按你说的内容自动带上（例如说“出 10 道练习题”会自动带上 `quiz`）。
  内置教学技能都声明了 `keywords`，命中更准；右侧「运行详情」里能看到本次实际带入了哪些技能。
- **硬性技能（`always: true`）**：有些规矩必须**每次**都生效，靠关键词命中不够保险——
  典型是 `figure-first`（"画函数图像、几何图形一律用 `show_figure`，不要开希沃白板"）。
  frontmatter 里写 `always: true` 之后，它**不管老师选没选、输的是什么都会注入**，
  技能中心里不给复选框、只挂一个「常驻」牌子。
  **这条不能靠改 `DEFAULT_SYSTEM_PROMPT` 代替**：老师在 `config\webui.json` 里改过
  `system_prompt` 的话默认提示词整个失效（真机上就栽在这，AI 还是去开希沃白板）。
- 技能支持 front-matter：

```markdown
---
name: courseware
description: 课件制作规范：课件页序、大字号、少字多图
keywords: 课件,做课件,PPT,幻灯片
always: true          # 可选：常驻（关不掉，每次必带）
---

# 具体规则（正文会被原样注入提示词）
- 每页不超过 5 行，正文不小于 24pt。
```

### 3.5 子代理（分派干活）、熔断与联网搜索

**子代理**：模型可以把相对独立的子任务派给子代理，主代理继续做其它部分。

- 一轮里派多个子代理时**并行执行**（已实测两个子代理同时开工）。
- 子代理有**独立上下文**和**受限工具集**（不能派子代理，避免无限套娃），默认最多 **256 轮**工具调用；
  一次运行最多派 4 个子代理（两项都能在设置里改）。
- 界面上有两处能看到子代理：
  1. 对话里是一张带蓝色边框的卡片（角色、任务、内部每一步工具调用、返回的结论）；
  2. **右侧「子代理」栏**——一眼看到当前有几个在干活（标题上写着"2 个正在工作 · 共 3 个"）、
     每个子代理的角色、正在执行的那一步、已走多少步、跑了多久，结束后标成"已完成/失败"并显示耗时。
     每次新运行会自动清空，只显示本次运行派出去的子代理。
- 系统提示词要求子代理直接干活、给出 200 字以内结论，不反问、不寒暄。

**熔断（防止思考打转）**：三种情况会自动停下并给出说明，不再继续烧 token。

| 触发条件 | 默认阈值 | 说明 |
| --- | --- | --- |
| 连续重复同样的动作 | 3 次提醒 / 12 次停 | 同一组工具调用（名称+参数）连续重复。**只提醒、不阻止**（对照 DSH 的 repeat-tool-reminder）：第 3、5、8 次会插一条"先分析上次结果、换方法或结束"的提醒，一直不听劝才停。**只读幂等工具**（截屏/列窗口/读文件/读剪贴板/搜索）与 15 字以内的短回答完全不计入 |
| 单轮思考过长 | 60000 字 | 例如推理模型在一轮里反复自我纠结 |
| 单次运行超时 | **0 = 不限制** | 长任务（画图、批量整理）默认不被墙钟时间砍断；需要时可设成具体秒数 |

熔断后在对话里插入一条醒目的「已自动熔断」提示，并说明建议（补充信息、换个说法、把任务拆小）。
熔断、工具轮次用尽、长度上限连撞多次、用户按 Esc 停止——这几种“没写完”的情况都会在消息底部留下
**一键「继续生成」**，点一下就从上次停下的地方接着写（标记存在会话里，刷新页面也在）。

### 长时间连续干活不中断（对照 DSH 的三个插件）

参考本机 DeepSeek Harness 的 `dsh-llm-retry`、`dsh-compaction-basic`、`dsh-compaction-tool-result-pruner`、
`dsh-repeat-tool-reminder` 实现，专门解决"干着干着就停"：

| 机制 | 行为 |
| --- | --- |
| **失败自动重试** | 限流(429)、服务端错误(5xx)、响应超时、连接中断这四类**在同一个步骤边界上重跑**：最多 5 次，指数退避 0.5s→10s 带 10% 抖动，尊重接口的 `Retry-After`。对模型不可见，老师只看到一条"接口被限流（第 2/5 次重试，1.0 秒后继续…）"。**空响应**另走"自动续写"（最多 3 次），并在历史里留一条说明 |
| **重试不产生重复内容** | 默认**攒够 8 个分片才把正文送到界面**，所以大多数抖动其实"没露出来"就重试掉了；万一已经露出来了，界面会先收到 `retry_reset` 把这一段作废再重画，不会出现两段重复的回答 |
| **上下文自动压缩** | 压力到模型上下文窗口的 80%（用接口报回的**真实 `prompt_tokens`** 计算）就把**最旧的一段**总结成一条 `<compacted-summary>` 摘要、最近 16% 逐字保留；原始消息归档到会话文件的 `compacted` 里（没删），第一条 user 消息（**原始任务**）永远留在最前面。压缩本身是一次单独的模型请求，不写进对话历史 |
| **超大工具结果先剪枝** | 压缩前先把超过 8192 字符的工具结果剪成「前 4096 + 中间省略标记 + 后 1024」，完整原文仍在会话文件里（回放/导出可还原） |
| **上下文超长自动恢复** | 接口明确报"上下文超长"时，绕过阈值做一次更狠的压缩（保留量减半）再重试，而不是把这一轮判死 |
| **流式卡住有超时** | 单次读取最多等 120 秒，卡住的连接按超时处理并进入重试，不会让老师对着转圈等到 300 秒 |
| **轮次给够** | 工具轮次上限默认 1024（子代理 256），可在设置里改；真正兜底的是压缩与熔断，不靠轮次卡人 |
| **超大工具结果落盘** | 结果超过 24000 字符时，完整内容写进 `工作区\工具输出\` 下的文件，模型只看到「开头 8000 + 结尾 4000 + 文件路径 + 原始大小」，需要细节再用 `read_file` 分段读（社区通行做法，避免一条命令输出吃掉半个上下文） |
| **加个文件不再整篇重写** | 改代码/长文档用 `edit_file`（查找→替换）：省 token、不会顺手改坏别处；匹配失败会指出文件里最像的位置，而不是让模型反复试 |
| **改完立刻查语法** | `write_file` / `edit_file` 写完 `.py`/`.json` 会做一次语法检查，有错就当场告诉模型去修（没问题时不打扰，省 token） |
| **截断的工具调用不会卡死** | 流式输出被截断时，`arguments` 会是半截 JSON。这种调用**不写进历史**，而是丢掉并重新生成这一步（最多 2 次），避免"每次请求都带着坏调用"导致的重试死循环（社区已确认的坑） |

设置里对应两个开关：**「上下文快满时自动压缩较早的对话」**（默认开）与**压缩阈值**（默认 0.8）。

### 这些机制是照社区踩过的坑定的（都能在 GitHub 上查到出处）

| 社区结论 | 我们怎么做的 |
| --- | --- |
| 工具输出太大要**落盘 + 只回预览**（pydantic-harness `ToolOutputLimits`、hermes-agent「recoverable truncation」） | 超过 24000 字符的结果写进 `工作区\工具输出\`，模型只看开头结尾 + 路径 + 原始大小 |
| 截断的 `tool_call.arguments` 会**卡死重试循环**（hermes #14443/#35151/#7680、opencode #18108） | 半截 JSON **不进历史**；先尝试**修复**（hermes #35574），修不好就重发这一步并丢掉坏调用 |
| `finish_reason=length` 与网络中断是**两类问题**（hermes #7680/#20975） | 长度截断的提示是"把参数写精简、长内容分多次写"；第二次重试再补一条更明确的精简提示 |
| 循环判定要看**结果有没有变化**，不能只看参数（langchain #36139、zeroclaw #2152） | 记录「签名 + 结果摘要」：结果在变就不算循环；一直返回同样错误则**更早**提醒 |
| 要抓**跨轮/交替**循环（oh-my-pi #3971） | 在最近 8 轮窗口里统计同一动作，A-B-A-B 也抓得到 |
| 检测到死循环应**暂停交给用户**（hermes #512 借鉴 Kilocode） | 先提醒（可劝 3 次）、屡劝不改才停，并且一定留下「继续生成」 |
| 长任务需要 **SSE 心跳**防断流（claude-code #25979/#70017、opencode #31281） | 服务端每 15 秒写一行 SSE 注释保活；前端解析器本来就忽略注释行 |
| 压缩输入必须**有上界**，否则永远压不动（pi #8371） | 摘要请求按"上下文窗口 × 35%"裁输入（中文按 1 字≈1 token 保守算） |
| 工具 schema 会**跟着每轮请求重发**，要精炼、能枚举就用 enum（tool-design principles） | 8 个易错参数加了 `enum`；测试守住"工具数量不明显减少 + schema 不超过 17000 字符" |
| 编辑要用**查找替换**而不是整篇重写（aider） | `edit_file`：容错匹配、重复段要求写长一点、找不到就指出最接近的位置 |
| 改完立即 **lint** 把错误喂回模型（aider） | `.py`/`.json` 写完立刻语法检查，有错当场报给模型

**联网搜索**：

- 内置 Bing（优先用结构稳定的 RSS 输出，失败再退回 HTML 解析）与 DuckDuckGo；Bing 实测 0.4 秒返回。
- **支持单位自建搜索接口**：在设置里填 `http://intranet/search?q={query}`，返回 JSON
  （含 `results` / `title` / `url`）或普通 HTML 结果页都能解析，适合完全离线的内网。
- `web_search` 支持指定 `engine`、`max_results`，以及 **`fetch_top`**：一次调用就把前 1-3 条结果的
  正文节选一起返回，避免"搜完再逐个打开"反复消耗 token。
- `read_url` 一次最多读 3 个链接（`urls` 数组），并且在没有 `agent.exe` 时用内置抓取兜底。
- 搜不到时模型必须如实说明，不允许编造标题或链接（实测中模型确实拒绝了编造）。
- 已知限制：百度、搜狗的 HTML 结果页有反爬（返回空壳页面），因此没有内置；
  DuckDuckGo 在部分网络下不可达，会自动跳到下一个引擎。

### 3.6 界面布局

- 只有中间的对话区滚动，**顶栏与左侧栏、右侧详情栏固定不动**；对话很长时右下角会出现「最新」按钮。
- 左侧栏结构（照 DeepSeek Harness）：品牌行 → 「新会话」「技能中心」→ **「工作区 · 当前目录名」标题行**
  （右侧三个图标：搜索对话 / 只看本工作区 / **新建工作区**）→ **按工作区分组的对话列表** → 底部快照与设置。
- **新建工作区 = 真的建一个文件夹**：点标题行右侧的「文件夹+」，弹出的是**工作区对话框**：
  上半部分是**已有工作区列表**（名字加粗、下面是完整路径、右边是对话条数，当前那个带「当前」标记，
  点任意一行就切过去，行尾的图标是在资源管理器中打开）；下半部分新建：填个名称（就是文件夹名），
  位置默认是安装目录下的 `workspaces`（可以「换个位置…」选到 D 盘、桌面、共享盘），
  下面**实时显示最终会建出的完整路径**——名称里有 `\ / : * ? " < > |` 这类 Windows 不允许的字符时，
  会当场说明「已自动去掉」并把按钮置灰；和目标同名会提示「另有一个同名工作区 …」，
  已经是工作区的目录会说明「会直接切过去用它」。点「新建并进入」后：文件夹建好、登记进侧栏、
  切为当前工作区，并在里面开好一个对话。想把已有文件夹收进列表，用「添加已有文件夹…」。
- **对话挂在工作区下面**：每个工作区那一行右边有「+」（在“某某”中新建对话）和「⋯」菜单
  （**重命名工作区** / 在资源管理器中打开 / 从工作区列表移除）。点工作区那一行 = 切到它并展开它的对话；
  点当前工作区那一行 = 收起/展开。对话行显示标题 + 相对时间（10 分钟 / 昨天 / 03-14）。
- 工作区可以重命名（只改显示名，不动文件夹，重名会提示）；「从工作区列表移除」只移除登记，
  **文件夹和会话都保留**，它的对话会落到侧栏的「未分组」下面，随时还能继续用。
- 没对话的工作区：新建/添加过的照样占一行（不然没法在它下面建对话）；从没登记过的空文件夹不占行，
  当前工作区名一直显示在「工作区」标题上。同名文件夹会带上父目录名（`高一\课件`、`高二\课件`），
  同一个目录的各种写法（`D:\课件`／`d:/课件/`／末尾多一个 `\`）都算同一个工作区。
- 「筛选」图标在「显示全部工作区 / 只看本工作区」之间切换；搜索框里输入内容时，会跨所有工作区平铺结果。

### 3.7 课堂互动与学习闭环

面向"老师上课"和"学生积累"设计的一组工具，都是作用在教室里的动作，不只是生成文件。

| 工具 | 老师怎么用 | 说明 |
| --- | --- | --- |
| `pick_students` | 叫人回答问题、分组活动 | **抽学号**，默认 1-50 号，不需要任何名单文件；**本轮不重复抽**，抽完一轮自动重开；班级人数用 `max_number` 指定；`mode="group"` 全班随机分组；结果直接投大屏 |
| `show_figure` | 数学课画函数图像、几何课画图形 | **画在网页的作图面板里**（不是希沃白板）。`kind=function` 给表达式（`sin(x)`、`x^2-2x-3`），`kind=geometry` 给图形描述（`A(0,0)`、`seg A B`、`circle O 3`、`poly A B C`、`angle A B C`）。**坐标是本地算的**：自写解析器求值、480 点采样、渐近线自动断开 |
| `class_timer` | 小组讨论、限时练习 | 大屏倒计时胶囊，大字显示，时间到自动响铃（浏览器不允许播放声音时静默）；`stop=true` 结束 |
| `show_on_screen` | 讲评、出题、板书 | **全屏大字投屏**，字号按教室后排可读设计（标题 6.2vh、正文 4.4vh）。`kind` 可选 题目/答案/要点/主题/提醒；Esc 或点空白关闭 |
| `mistake_book` | 记错题 → 出重练卷 | 按知识点积累错题（题目/答案/错因），`stats` 看知识点分布找薄弱点，`practice` 生成重练 docx（题目在前、参考答案另起一页、附错因提示），练过的题会记次数、下次优先出没练过的 |
| `score_stats` | 考完试的统计 | **用代码精算**平均分、中位数、标准差、极差、及格率、优秀率、分数段分布，避免模型心算出错；可存成 xlsx 汇总表；默认不列学生个人分数（`show_names` 才列前 3 后 3） |

配套技能：`classroom`（一节课的节奏：导入→讲授→提问→练习→讲评→小结，以及每个环节该用哪个工具）、
`flashcards`（复习卡/记忆卡，导出可打印或可导入的 CSV）、`tiered-homework`（基础/提高/拓展三档分层作业，
含用时估计与答案页）、`explain-simply`（先定位卡在哪一步，再用一个类比分步讲，最后让学生复述）、
`socratic`（五级追问阶梯，不给答案）、`error-analysis`（错题四类归因 + 3+2+1 补救练习）、
`doc-to-questions`（课件/文档变记忆·理解·应用三层随堂问题）、`parent-report`（给家长的 150-250 字反馈）。

典型一节课的用法：

```text
（老师）这节课讲分数的初步认识，先抽 2 个学号回答问题
→ 大屏出现「请回答：学号 12、35」
（老师）出一道通分练习题并开始 3 分钟倒计时
→ 大屏全屏显示题目，右上角出现 03:00 倒计时
（老师）这些题错的都是通分，记进错题本，然后生成重练卷
→ workspace\错题本.json + 错题重练卷_通分.docx
（老师）统计这次期中成绩，给我及格率和分数段
→ 平均分 77.00、及格率 80.0%、优秀率 40.0% + 分数段表 + 成绩分析.xlsx
```

**隐私**：错题本与成绩统计默认不投屏、不列学生个人分数；涉及学生姓名分数时只在本机文件里处理。

#### 3.7.1 抽学号的两个按钮 + 悬浮工具栏

**大屏上那两个按钮**（0.6.0 新增）。抽到学号后，大屏（`kind: "pick"`）底部会出现：

- **完全重置抽取记录**：把这一轮抽过的学号**全部清空**（1-N 号重新都可抽），
  屏幕上显示「抽取记录已完全重置」，**不会顺手再抽一个**——想开始就点「抽下一个」。
- **抽下一个**：再抽一个**这一轮还没抽到**的学号，结果直接换上大屏。

两个按钮都走 `POST /api/classroom/pick`，记录写在会话文件的 `picked_numbers` 里，
所以**和模型抽的是同一个池子**（不会出现"模型抽过 23，按钮又抽到 23"），刷新页面也还在。
正在生成中时会明确拒绝（409），不会出现"抽了但被覆盖"。

**悬浮工具栏**（0.6.0 新增，`scripts\study7agent-float.ps1`）。
`server.py` 一起来就把它拉起来（**只有 `--no-float` 能关**；开不开系统浏览器是另一回事，
内嵌内核版永远带 `--no-open`，但工具栏照起）。它是屏幕右侧一条置顶小工具条：

- 点顶部彩色标题栏 = 网页切到前台；按住可以拖动（拖不出屏幕）；
- 右上角「**收起**」= 缩成右边一条 46×138 的窄条（图标 + **当前时间** + 展开 + 退出），
  再点「展开」回来。时间由独立的 1 秒定时器走，**跟网络无关**。状态记在 `logs\float-ui.txt`，
  **收起一次以后就一直收着**；
- 关闭网页 = 几秒后工具栏 + Web UI 服务 + 控制台窗口一起关闭（`F5` 不会误伤）；
- 「退出（连服务一起关）」按钮做同样的事。

外观上做了圆角 + 1px 描边 + 渐变标题栏 + 圆角卡片按钮：无边框置顶小窗不这么处理，
贴在一体机桌面上会糊成一块。

工具栏**只做三件事**：转给服务端、让网页执行一条排队的命令、或者就地做一个"切窗口"动作：

| 按钮 | 走哪条路 |
| --- | --- |
| 希沃白板 / 希沃展台 / QQ | **先切、切不到才启动**：先在本地找它的窗口（**包括收进托盘那种隐藏的**——QQ 点 X 是藏进托盘，`IsWindowVisible` 变 0），找到就 `ShowWindow(SW_SHOW)` + 切到前台，**不启动**；一个窗口都没有才让 `apps.py` 启动（三级查找：`config\float.json` → 常见安装目录 → 开始菜单快捷方式名），起来后再切前台。顺序反了会弹出新的登录窗口 |
| **切到PPT** | **本地动作，不走网络**，而且分两段：① 先在本地找正在运行的 WPS 演示 / PowerPoint 并切到前台（不碰硬盘、不启进程，<200ms）；② **一个都没开**时才让服务端用默认应用打开**最近收到的那份课件**，起来后再切到前台 |
| **回到桌面** | **本地动作**：`Shell.Application.MinimizeAll()`，然后把工具栏自己恢复成正常状态（否则它会被一起最小化，老师就点不到它了） |
| 截图给AI / 板书保存 / 课堂标记 | 服务端截屏落盘（`工作区\截图`、`工作区\板书`、`工作区\课堂时间点.json`），网页那边收到一条提示或一张待发送的图片 |
| 计时 / 抽学号 / 数学函数 / 几何画板 | 排一条命令给网页，网页执行原本就有的功能（计时窗口 / 大屏抽学号 / 打开作图面板） |

**切窗口为什么不能用 `AppActivate`**：它对**最小化的窗口直接返回 False 而且什么都不做**
（真机实测：最小化 WPS 演示后 `AppActivate` → False，`ShowWindow(SW_RESTORE)` +
`SetForegroundWindow` + `AttachThreadInput` → True）。另外 **WPS 12 是单 exe**
（`wps.exe /wpp`，没有 `wpp.exe`），进程名名单里必须有 `wps`。

**「切到PPT」找不到课件时去哪找**：**网页「设置」里的「悬浮工具栏」那一段就能填**
（`qq_download_dir`）。填了就**只看那个目录**；没填才去猜
`文档\Tencent Files\<QQ号>\FileRecv`（经典 QQ）、`...\nt_qq\nt_file`（QQNT）、
`文档\Tencent Files`、系统下载目录。**QQNT 的下载路径存在它自己的数据库里，外面读不到**，
所以猜不中时设置界面会提示去哪找（QQ 的「设置 - 基本设置 - 文件管理」）。
同一段里还能填希沃白板 / 展台 / QQ 的 exe 路径；这几项都存在 `config\float.json`，不进包。

服务端接口：`POST /api/float/command`（干活，返回纯文本 `OK|消息|focus=0/1`）、
`GET /api/float/state`（网页还活着吗，纯文本）、
`GET/POST /api/float/config`（读写 `config\float.json` 里那几项）、
`POST /api/float/ping`（网页报活 + 取排队的命令）、`POST /api/float/bye`（关页面时说一声）、
`POST /api/float/quit`（连服务一起退）。
返回纯文本是因为 **PowerShell 2.0 没有 `ConvertFrom-Json`**。

#### 3.7.2 作图面板（函数图像 / 几何图形）

以前的"数学函数 / 几何画板"是靠 `draw_path` 指挥鼠标在希沃白板里画——慢，还容易画歪。
0.6.0 换成了**自己的作图引擎** `webui\plot.py`：

- **老师**：顶栏「作图」按钮，或悬浮工具栏的「数学函数 / 几何画板」，打开作图面板——
  **面板底下就有一行输入框**，函数直接写 `sin(x)`、`x^2 - 2x - 3`、`2x+1`
  （支持 sin/cos/tan/sqrt/abs/ln/log/exp 和 pi），点「画出来」立刻出图；
  几何切到「几何」模式，分号隔开多条（`A(0,0); B(4,0); C(0,3); poly A B C`），
  中文别名 `线段/直线/圆/多边形/角` 也认。
- **也可以直接在面板上让 AI 画**：输入框里写一句话（"画一个底 4 高 3 的直角三角形"）点「让 AI 画」，
  这句话就当成普通提问发出去，AI 用 `show_figure` 把图画回**同一块面板**。
  **面板上会有一条状态**（输入框上面）：等的时候是蓝点 +「AI 正在思考，画好会直接出现在上面…」，
  画好了变绿点 +「画好了」（8 秒后自己消失），这一轮结束还没画就变黄点 +
  「AI 这一轮没有画图，看看对话里它说了什么」——**不会一直转圈骗人**。
  以前这里只弹一个两秒的 toast，老师盯着一块空白面板不知道 AI 到底在不在干活。
  **画完只把结果显示在面板里，不会把窗口弹到最前面**——老师可能正在看别的程序，
  突然弹出来是打断他。
- **AI 默认就该用它**：系统提示词里写明了"画函数图像、几何图形一律用 `show_figure`，
  不要开希沃白板、也不要用 `draw_path` 描"；`draw_path` 的描述里也加了反向指引。
- 「更多设置」里能改横轴范围、用多行文本框逐条写图形。

几个刻意的决定：

- **坐标全在本地算**：让模型吐几十上百个采样点又贵又容易算错，让它给**表达式**最省也最准；
  图画错了在课堂上是硬伤。表达式用自己写的递归下降解析器求值，**绝不 eval**（有用例盯着）。
- **渐近线要断开**：`1/x` 画成两支（不是一条竖线），`tan(x)` 断成 7 段。
- **几何必须等比**：不然直角会画成不是直角。
- 页面上只用 SVG 画（和图标一套路子），刻度步长取 1/2/5×10^k，原点只标一个 0。

接口：`POST /api/figure`（老师那条路，和工具共用 `plot.build()`）。


### 3.8 电脑操作（截屏 / 窗口 / 鼠标键盘 / 剪贴板 / 音量）

这一组工具解决的是"屏幕上发生的事"——投影没出来、弹窗不会点、视频声音太大、
要在希沃白板里画个图。**注意这是真有副作用的操作**：默认**不问，直接执行**（免确认），
想收紧时在设置里打开对应开关即可。

| 工具 | 典型说法 |
| --- | --- |
| `snapshot` | "屏幕上这个弹窗是什么意思？" |
| `screenshot` | "把现在这屏存下来" / "看看鼠标指到哪了" |
| `app` | "把希沃白板切到前面" / "关掉那个广告窗口" / "打开计算器" |
| `click` | "点那个『确定』" |
| `type` | "把这段评语打进去" |
| `shortcut` | "按 Ctrl+S 保存" / "把视频暂停一下" / "声音小一点" |
| `clipboard` | "我复制的东西呢" / "帮我放进剪贴板我自己粘" |
| `scroll` | "往下翻一页" |
| `move` | "在白板上画一条横线"（`drag=true`） |
| `wait_for` | "等这个窗口出来再说" |

几个实现上的关键点（都做过实测）：

- **看界面**：`snapshot` 一次给两样东西——画面（**带红字编号**的截图）和可操作元素清单。
  截图上的编号就是清单里的 `[N]`、也就是工具里的 `label=N`；清单每行带控件类型、名字、中心坐标、
  当前值和它能做哪些动作（`fill`/`toggle`/`select`/`slide`/`scroll`/`click`）。
  `click(label=3)` / `type(label=3, text=…)` / `scroll(label=3)` 会**按动手那一刻的界面重新算坐标**，
  元素对不上就明确拒绝（不会拿着过期坐标乱点）。
- **截图给模型看**：截完的图会像 `view_image` 一样注入下一轮，模型是真的"看见了"再回答，
  不是凭文字猜。超过 8MB 会自动按 0.6/0.4/0.25 缩放重截成更小的 PNG（底座只有 PNG 编码器），
  避免"图太大注入不进去、模型却假装看到了"。
- **这一版是真鼠标真键盘**：点击、打字、滚动、拖动、快捷键都是 `SetCursorPos` + `mouse_event` /
  `keybd_event` 真发出去的，**没有**"不碰指针也能操作界面"的通道（旧版走 UIA Invoke/Value，
  已在 1.1.0-beta9 整体换掉）。按 `label` 只能保证点对控件，保证不了不移动鼠标。系统提示因此要求：
  能用命令行/文件/剪贴板/`app` 办成的事优先用那些，真要动鼠标先说一句。
- **多显示器与 DPI**：`display_inventory` 告诉你几块屏、各自的矩形与工作区；`screenshot(display=N)`
  只截某一块，`region=[x1,y1,x2,y2]` 截任意矩形。`loc` 与清单里的坐标都是**虚拟桌面的物理像素**，
  ctypes 层先声明 DPI 感知再抓屏，截图与鼠标在同一个像素空间里（125% 缩放的机器上也不会偏）。
- **截图是从屏幕 DC 抓的**：被别的窗口挡住的窗口，拍到的是挡在前面的东西；最小化的窗口先
  `app(mode="switch")` 切回来再看。管理员权限的窗口点不动（系统 UIPI 限制），会如实报错。
- **中文输入**：`type` 走 `KEYEVENTF_UNICODE` 逐字注入，**不切输入法、不占剪贴板、不用 SendKeys**。
- **为什么不再"Python 拼 PowerShell"**：每个动作都新起一个 PowerShell 进程要 500 毫秒起步，量下来
  抓屏要 0.5 秒、一次 UIA 快照要 1 秒上下。现在分成四层：`winapi.py`（ctypes 直连 user32/gdi32，
  GDI `BitBlt` 抓屏 40 毫秒左右）、`winimage.py`（BGRA 缓冲 + 编号标注 + 手写 PNG，约 200KB/85 毫秒）、
  `uia.py` + `uia_worker.ps1`（**常驻一个** PowerShell 进程答 UIA 查询，首次约 1 秒，之后毫秒级）、
  `desktop.py`（动作与查询）。仍然只用 Win7 自带的东西，不装任何第三方组件。
  **`uia_worker.ps1` 必须保持纯 ASCII**：PowerShell 5.1 把无 BOM 文件按 ANSI 读，C# 段里写中文会让
  `Add-Type` 直接编译失败。
- **停止按钮能打断**：`/api/stop` → `desktop.set_cancel` → `uia.set_cancel`，正在跑的界面查询会放弃。

**开关**：设置 → 电脑操作。
- `允许桌面操作`：关掉后这一组工具直接不可用。
- `动鼠标键盘这类操作前先问我`：**默认关闭**（不弹确认框，说一句就干完）。打开后，点鼠标、打字、
  发快捷键（含多媒体键）、滚动、拖动、批量填表、关窗口、改剪贴板、结束进程、改注册表都会先弹一个
  写明"要做什么"的确认框；只读的 `snapshot`/`screenshot`/`display_inventory`/`process(list)`/
  `registry(get)` 不打扰。
- `发邮件 / 推群 / 发 QQ 消息前先问我`：**默认关闭**。打开后每次对外发送前都会先确认。

两个开关互相独立，可以只收紧其中一类。**默认免确认意味着模型可以直接动你的鼠标、替你发消息**，
如果你把电脑借给别人或让模型跑不熟悉的任务，建议把这两个开关打开。

### 3.9 消息通知（邮件 / 群机器人 / QQ）

| 工具 | 通道 | 可靠性 |
| --- | --- | --- |
| `send_email` | QQ 邮箱、163、学校邮箱（SMTP） | 高：标准协议，能带附件，发送成功/失败都有明确回执 |
| `notify_webhook` | 企业微信 / 钉钉 / 飞书群机器人 | 高：一个网址即可，群里立刻可见 |
| `send_qq_message` | 本机 QQ 客户端 | 中：**模拟操作**（切窗口→输入→回车），发完自动截图供核对 |

配置（设置 → 消息通知）：

- **QQ 邮箱**：设置 → 账户 → 开启「POP3/SMTP 服务」→ 拿到 **16 位授权码**填到「密码/授权码」。
  **QQ 邮箱不能用登录密码发信**，这是最常见的失败原因（报错会直接这样提示）。
- **群机器人**：企业微信「群 → 群机器人 → 添加」或钉钉「群设置 → 智能群助手 → 添加机器人 → 自定义」，
  复制 Webhook 地址粘进来。企业微信/钉钉的文本消息格式相同，飞书是另一套，界面里可选。
- 授权码和 Webhook 地址**只存在本机 `config\webui.json`**，设置界面里只显示尾号掩码，
  留空保存 = 不修改（不会把已存的密钥清掉）。

关于 QQ：**没有做"QQ 机器人"**。真正的 QQ 机器人要注册开发者账号、跑常驻服务、联网登录，
在老师这台 Win7 上既装不了也维护不了。所以走的是"用已经登录的 QQ 客户端发消息 + 截图核对"，
并且明确告诉你它的局限：需要 QQ 已登录、需要目标聊天窗口已打开，
QQ 里设了「Ctrl+Enter 发送」时要用 `send_shortcut="ctrl+enter"`。**发完请看截图确认**，
不要假定消息一定送到。

所有对外发送（邮件/群推送/QQ）默认**直接发送**，不再弹确认框；想每次先过目一遍，
就把设置里的`发邮件 / 推群 / 发 QQ 消息前先问我`打开。

## 4. 安全边界

- **文件读写范围**：默认允许读写工作区之外的任意绝对路径（例如 `D:\`、桌面、共享盘），
  这样模型才能真正帮你改别的目录里的文件；想收紧时在设置里取消勾选
  “允许读写工作区之外的路径”即可。系统提示词会跟随该开关变化，权限放开时模型不会再反复索要授权。
- **系统目录不允许写入**：`%SystemRoot%`（`Temp` 除外）、`Program Files`、随包的 `python` 目录
  一律拒绝写入。读不受影响，工作区/桌面/D 盘/共享盘也不受影响。这一条挡的是“网页或搜索结果里
  夹带的指令让模型去覆盖系统文件”这类提示注入，不是限制正常使用。
- 命令策略与 CLI 完全一致（等价的 `internal/safety` 实现）：`blocked_prefixes` 直接拒绝，
  `confirm_prefixes` 与 `always_confirm` 走界面确认；命令支持 `&`、`|`、`cmd /c` 等嵌套写法识别。
  另外**先去掉 cmd 的 `^` 转义再判断**，并把 `start` / `for … do` / `call` / `if` 这类“会再执行一次参数”
  的写法按参数递归检查——`p^o^w^e^r^s^h^e^l^l …`、`start /min powershell …` 现在都会正常弹确认框。
- 所有命令追加写入 `logs\commands.log` 审计日志（制表符转义，格式与 CLI 相同）；
  日志写不进去时会在这条工具结果里明确说明，不会“执行了却没有记录”。
- 服务默认只监听 `127.0.0.1`。若改为对外监听（`host` 改成 `0.0.0.0`，例如用平板遥控教室电脑），
  **没配令牌时会自动生成一个并写进 `config\webui.json`**，命令行里打印带令牌的地址；
  界面会把令牌记住并attach在每个请求上。同时会拒绝来自其它站点的跨站请求（CSRF）。
- **同一个对话同时只会跑一个**：两个窗口一起提问会互相覆盖对话记录，第二个会收到明确的提示。
- API Key 只保存在服务端 `config\agent.json`，界面仅显示掩码。
- 界面上的「打开」按钮只允许打开非可执行文件（`.exe/.bat/.cmd/.ps1/.vbs` 等一律拒绝），
  上传接口同样拒绝可执行文件；文件选择器只列目录、不返回文件内容（图片预览接口仅接受图片格式）。

## 4.1 浏览器要求（含 360 / QQ / 搜狗浏览器）

| 浏览器 | 是否可用 | 说明 |
| --- | --- | --- |
| Chrome / Edge 109 及以上 | 可用 | Windows 7 上最后一个 Chrome 大版本是 109 |
| Firefox 115 ESR | 可用 | Windows 7 上的 ESR 版本 |
| 360 安全浏览器 / 极速浏览器 | **可用（必须极速模式）** | 极速模式是 Chromium 内核；当前版本已到 Chromium 132 |
| QQ 浏览器、搜狗浏览器 | 可用（极速模式） | 同上，属于 Chromium 双核浏览器 |
| 360 等浏览器的“兼容模式” | **不可用** | 兼容模式是 IE 内核，没有 `fetch` / 流式响应 |
| IE 11 | 不可用 | 缺少 fetch 与流式响应能力 |

对双核浏览器做了三层处理：

1. 页面头部声明了 `renderer=webkit` 与 `force-rendering=webkit`，双核浏览器会优先选择极速模式。
2. 启动时检测内核：如果落在 IE 兼容模式或内核过旧，界面会直接给出中文提示，
   告诉你点地址栏右侧的内核切换按钮改成“极速模式”，而不是抛一句“网络错误”。
3. 右侧“环境”卡片会显示当前浏览器与内核版本（例如 `360 浏览器 · Chromium 86`），便于现场排查。

内核低于 Chromium 84 时功能正常，只是界面元素间距会略紧（旧内核不支持 flex gap），界面会提示升级。

`^` 转义与 `start`/`for … do` 绕开确认框、UNC 工作目录、命令超时后连子进程一起结束、
审计日志写不进去时的提示、并发运行同一会话的拒绝、断开客户端后的自动取消、局域网模式的令牌。

0.6.0 新增的一批用例：抽学号两个按钮的接口（不重复抽、重置只清空不抽、班级人数改小后
旧记录不作数、生成中回 409 而不是丢数据）、悬浮工具栏的信箱（心跳报活、`bye` 把时钟往前拨
又能被刷新收回、命令只发一次、动作不认识回 `ERR`、失败的动作不排命令、
`/api/float/quit` 真的去结束进程、退出延时的钳制）、外部应用查找（`config\float.json`
覆盖优先、坏配置不致命、找不到时给可操作说法）、**作图引擎**（表达式求值表、报错要说得清、
源码里不许出现 eval/exec、`1/x` 必须断成两支、几何语法与中文别名、几何报错要指到具体那个点、
`/api/figure`、`show_figure` 推事件、`/api/classroom/materials` 只列工作区里的目录），
以及悬浮工具栏脚本的静态+真机检查（必须 UTF-8 **带 BOM**、不许出现 PowerShell 3 才有的语法、
按钮覆盖服务端认识的全部动作、**真跑一遍 `-SelfTest`** 确认能建出窗体、按钮的处理块接对了、
折叠/展开的宽度对）。

生成质量另有一条真机验证路径：本机装有 PowerPoint / WPS 时，直接双击打开生成的课件核对页数即可；

## 8. 常见问题

- **浏览器打不开 / 界面空白**：先看右侧“环境”卡片里的浏览器内核。Windows 7 上建议 Chrome 109
  或 Firefox 115 ESR；360 / QQ / 搜狗浏览器请切到“极速模式”（见 4.1 节），IE 内核不支持流式对话。
- **找不到设置按钮**：顶部工具栏最右侧的齿轮就是设置入口，左侧栏底部也有一个“设置”按钮；
  窗口较窄时左侧栏会收起，点顶部的菜单按钮可以展开。工作区与技能按钮就在齿轮左边。
- **生成的文件在哪里**：默认在解压目录的 `workspace\`；点顶部的「工作区」按钮能看到文件列表并一键打开，
  也可以换成桌面或 D 盘等位置。
- **选择文件时看不到某个目录**：选择器默认从工作区开始，点顶部「上一级」或盘符（C:/D:/E:）逐层进入；
  也可以在弹窗右上角用「从电脑选择文件」走系统文件对话框。
- **提示未配置模型**：在“设置”里填写模型名称与 `base_url`，或直接编辑 `config\agent.json`。
- **接口地址怎么写**：`https://api.deepseek.com`（裸域名）、`https://api.deepseek.com/v1`、
  或完整地址都可以，服务端会自动补全，设置里会显示“实际请求地址”。
- **模型不肯改工作区外的文件**：确认设置里“允许读写工作区之外的路径”已勾选（默认勾选），
  系统提示词会据此告诉模型可以越界读写。
- **端口被占用**：`start-webui.cmd --port 8899`，或在设置中修改端口后重启。
  如果占用端口的正是本程序（经常是双击了两次），启动器会认出它并直接打开已经运行的那个页面。
- **想用其它数据目录**：设置 `data_dir`，会话、快照、上传文件都会放到那里。
- **不想要屏幕右边那条小工具条**：启动时加 `--no-float`（`start-webui.cmd --no-float`）。
- **工具条说找不到希沃白板 / 展台 / QQ**：把它的 exe 路径填进 `config\float.json`，
  格式见 `docs\user-manual-zh.md` 的「悬浮工具栏」一节；填完不用重启。
- **关掉网页后工具条还在**：正常情况下几秒内会一起关掉；如果服务卡住没退，点工具条的
  「退出（连服务一起关）」，或在控制台窗口按 `Ctrl+C`。
- **命令没有输出 / 中文乱码**：中文 Windows 控制台默认 GBK。服务端先认 BOM，再按 UTF-8、
  GB18030 解码，还解不干净时（例如读到一半被截断）会在两种容错解码里挑坏字符更少的那个，
  并把实际使用的编码写进工具返回里。若仍异常，可在命令前加 `chcp 65001 >nul &&`。
- **打开文件时提示“正在被其它程序占用”**：先关掉打开它的 Word / WPS / 播放器；这是 Windows
  的共享冲突，程序已经把它翻译成了可读提示。
- **路径太长（超过 260 字符）**：Windows 7 的路径上限就是 260。程序对读写会自动加 `\\?\` 前缀
  绕过限制；实在超长时（比如共享盘里层层嵌套）建议把文件放到浅一点的目录。
- **Python 起不来（窗口一闪就没了）**：Windows 7 上通常是缺“通用 C 运行库”。
  装 Microsoft Visual C++ 2015-2022 Redistributable（x86 和 x64）或系统更新 KB2999226 即可；
  启动器会先自检 Python 能不能运行，并把这个提示打印出来。
