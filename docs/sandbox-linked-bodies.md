## 1. 场景 JSON 扩展（顶层键）

现有键一律不动：`tracks` / `fields` / `bodies` / `g` / `duration` / `dt` / `restitution`。

新增（全部可选；旧场景没有这些键时**行为和现在完全一样**）：

```jsonc
{
  // 板 / 小车 / 挡板：有质量、能平动（默认不转），可以挂轨道、受摩擦和弹簧/绳的力
  "plates": [{
    "id": "car", "name": "小车",
    "at": [2.2, 0.12],          // 板的中心（世界坐标）
    "size": [2.0, 0.24],        // [宽, 高]
    "mass": 3.0,
    "v": [0.0, 0.0],            // 初速度（默认 0）
    "angle": 0.0,               // 初始倾角（度，默认 0；逆时针为正）
    "lock_rotation": true,      // true=不转（板块题默认）；false=会转（有转动惯量）
    "fixed": false,             // true=钉死（挡板/斜面底座），不参与动力学
    "mu_ground": 0.0,           // 板与地面之间的动摩擦因数（默认 0=光滑）
    "support": "ground"         // ground（默认，落在 y=0 地面）| "none"（悬空，靠连接体/轨道撑）
  }],

  // 轮子：圆盘，默认纯滚动（不打滑），能挂在板下面当车的轮子
  "wheels": [{
    "id": "w1", "name": "轮子",
    "at": [1.2, 0.15], "radius": 0.15, "mass": 0.5,
    "v": [0.0, 0.0],
    "roll": true,               // true=纯滚动；false=像冰面一样滑（没有转动）
    "mu": 0.6,                  // 与地面/轨道的静摩擦上限（roll=true 时用）
    "plate": null               // 可选：写成某个 plate 的 id 表示这是它的轮子（跟着板走、由板带动转）
  }],

  // 弹簧：两端各接一个东西（板 / 物块 / 轮子）或一个固定悬挂点
  "springs": [{
    "id": "s1", "name": "弹簧",
    "a": "p1", "at_a": [0.0, 0.0],     // at_a 是相对 a 中心（或物块中心）的挂点，默认中心
    "b": "car", "at_b": [-1.0, 0.0],   // b 为 null 时用 "anchor": [x, y] 接世界固定点
    "k": 200.0, "rest": 0.5,           // 劲度系数 N/m、原长 m
    "damping": 0.0                     // 阻尼 N·s/m，默认 0（理想弹簧）
  }],

  // 连接体：轻绳 / 轻杆
  "links": [{
    "id": "l1", "name": "轻绳",
    "kind": "rope",             // rope=只能拉不能推（松弛就没力）；rod=刚性（拉压都管）
    "a": "ball", "at_a": [0.0, 0.0],
    "b": null, "anchor": [1.0, 2.6],   // b=null 表示接世界固定点（单摆的悬挂点 O）
    "length": 1.8               // 绳长 / 杆长（米）
  }],

  // 轨道挂到板上：坐标写在被挂板的**局部坐标系**里（原点=板中心，x 向右，逆时针为正）
  "tracks": [{
    "id": "top", "kind": "line", "points": [[-1.0, 0.12], [1.0, 0.12]], "mu": [0.1],
    "body": "car"               // ← 新增键；不写就是原来的静态轨道
  }],

  // 悬挂点（只是给界面画个点、方便老师拖；引擎从 links[].anchor 读坐标）
  "anchors": [{ "id": "O", "at": [1.0, 2.6], "name": "悬挂点 O" }]
}
```

### 语义（引擎必须做到）

1. **板**：`fixed=false` 时按刚体平动（`lock_rotation=true` 不转）或刚体平面运动积分；
   受重力、地面支持力/摩擦（`mu_ground`）、挂在上面的轨道给它的反作用力、弹簧力、绳/杆约束力。
   `support="ground"` 时板的竖直方向被地面托住：重力被支持力抵消，**只有水平方向需要动力学位移**
   （板块题最常见）；`support="none"` 才允许竖直加速度。
2. **挂轨道的板**：轨道几何每步跟着板的位姿变换；**物块在挂板上轨道跑时，轨道和物块之间有法向力 N
   与摩擦力 f，这对力大小相等方向相反**——物块推板，板才会被推动；摩擦生热按"物块相对轨道表面的
   滑动距离"算（板也在动，不能再用旧的"沿世界坐标弧长×μN"）。
3. **单摆**：`links` 里 `kind="rope"` 且 `length` 为绳长、`b=null` 接世界点时就是一个单摆；
   绳拉直时**速度约束**（沿绳方向相对速度为 0）、松弛时无力；摆球是普通 `bodies` 里的质点，
   所以碰物块直接走现有碰撞逻辑（`restitution` 调 1.0 就是弹性碰撞）。
4. **弹簧**：两端点之间 `F = -k(|x|-rest) - damping·v_rel`，两边各受一半；弹簧势能
   `0.5k(|x|-rest)^2` 必须进能量账（否则 `energy_gap` 会漂）。
5. **绳/杆**：`rod` 距离约束（拉压都管、理想无能量损失）；`rope` 只有拉直时才约束。
   两个物体之间的约束力是内力，**动量严格守恒**。
6. **轮子**：`roll=true` 时 `v = ωr`（纯滚动，静摩擦不耗能）；`plate` 非空时中心跟着板走、
   沿板速滚转，只是"车的轮子"的画法/转动，不额外改变板的动力学（除非它也贴地，那就按接触判）。
7. **地面**：`y=0` 是地面（和现在画布一致）。物块掉到地面以下仍然按"跑出场景"处理。

**必须成立的数（优先级从高到低）**：
1. 摆球最低点（碰前瞬间）速度 ≈ **6.0 m/s**（√(2gL)，L=1.8，g=10）。
2. 弹性碰撞后：物块 **3.0 m/s** 向右、摆球 **-3.0 m/s**（向左）；物块受冲量 **3.0 N·s**。
3. 物块在粗糙段滑 1 m（相对小车）到圆弧最低点：摩擦生热 ≈ **1.0 J**；

   推导：相对减速度 `μg(1+m0/M)=1.3333`，v_rel²=9-2×1.3333×1=19/3。
4. 物块滑到圆弧最高点（局部高度 0.125 m，速度竖直、小车水平）：小车 **0.75 m/s**、
   物块水平分量 0.75 m/s、竖直分量 **1.5 m/s**，合速度 **3√5/4 ≈ 1.6771 m/s**。
5. 动量守恒：全过程 x 方向总动量恒为 **3.0 kg·m/s**（碰后到结束；碰前是摆球给的冲量，注意分段）。
6. 能量账：碰后到圆弧最高点，动能+势能损失只来自粗糙段摩擦 ≈ **1.0 J**（无其它损失）。

## 6. 装配口径与参考题数值

这一节是引擎实现的实机口径，界面和 Lead 都按它验收。**字段名不要自己改**，要改先在群里问。

### 6.1 两条不能动的口径

1. **骑在轨道上的物块，中心就在轨道线上。** radius 只用于物块互撞和画图，不把中心沿法向抬一个半径。
   老师原题的圆弧顶只抬升 R=0.125 m，物块竖直速度 1.5 m/s；若把中心沿法向外偏，弧顶只抬 0.075 m，
   vy 会变成 1.80，3√5/4 就不成立了。旧 sim2d 也是这个约定。
2. **「相对滑过 1 m」指物块相对轨道表面的位移**，不是世界坐标位移；生热 Q = μN × 相对滑过的路程。
   挂在板上的轨道每步随板的位姿变换，摩擦用的相对速度是物块相对「轨道接触点」的速度。

### 6.2 老师那道题的完整场景（sim2d.example("exam")）

```json
{
  "tracks": [
    {"id": "粗糙段", "kind": "line", "points": [[-1.105, 0.10], [-0.105, 0.10]], "mu": 0.1, "body": "car"},
    {"id": "弯道", "kind": "circle", "center": [-0.105, 0.225], "radius": 0.125,
     "inner": true, "arc": [270.0, 360.0], "mu": 0.0, "body": "car"}
  ],
  "plates": [
    {"id": "car", "name": "小车", "mass": 3.0, "size": [2.4, 0.2], "at": [3.0, 0.1],
     "support": "ground", "lock_rotation": true, "mu_ground": 0.0}
  ],
  "bodies": [
    {"id": "blk", "name": "物块", "mass": 1.0, "radius": 0.05, "at": [1.895, 0.20], "v": [0.0, 0.0]},
    {"id": "ball", "name": "摆球", "mass": 0.3333333333333333, "radius": 0.05,
     "at": [0.0, 2.0], "v": [0.0, 0.0]}
  ],
  "anchors": [{"id": "O", "at": [1.8, 2.0]}],
  "links": [{"id": "绳", "name": "绳", "kind": "rope", "a": "ball", "anchor": "O", "length": 1.8}],
  "g": 10.0,
  "duration": 2.0,
  "restitution": 1.0
}
```

口径说明：

- 轨道 points / center 都是**板的局部坐标**（原点在板中心，x 向右、y 向上），每步按板的位姿做局部→世界；
  body 写板的 id。
- arc: [起角, 终角]，单位是度、逆时针为正、跨度 ≤ 360°：[270, 360] 就是从最低点（270°）到右侧（360°）
  的 1/4 弧；不写 arc 就是整圆（旧行为一点不变）。
- 物块 at 放在粗糙段左端 (1.895, 0.20)，比摆球最低点（绳长 1.8，吊在 x=1.8）右 0.095 m，
  保证一定撞上而不是相切。
- 摆球从水平位置释放（锚点 (1.8, 2.0)，绳长 1.8，摆球在 (0, 2.0)）。
- 不写 dt 就用 5e-4 s；帧仍按 5 ms 采样（老师看到的滑条步长不变）。
  引擎内部每个采样步再分 4 个子步积分（弧段的离散耗散跟子步长成正比），这是实现细节，界面上看不出来。

### 6.3 七个期望值与容差

相对误差 1% 以内（动量、能量用绝对阈值）：

| # | 物理量 | 期望值 | 容差 | 引擎实测 |
| --- | --- | --- | --- | --- |
| 1 | 碰前摆球速度 | 6.0 m/s（√(2gL)） | 1% | 5.99889（-0.02%） |
| 2 | 碰后物块 / 摆球 | +3.0 / -3.0 m/s | 1% | 2.99530 / -2.99900 |
| 2 | 物块受到的冲量 | 3.0 N·s | 1% | 2.99530 |
| 3 | 粗糙段生热（相对滑 1 m） | 1.0 J（μN·s = 0.1×10×1） | 1% | 0.99990 |
| 3 | 此刻小车 / 物块速度 | 0.1208 / 2.6374 m/s | 1% | 0.12084 / 2.63694 |
| 4 | 弧顶小车 / 物块水平 / 竖直 | 0.75 / 0.75 / 1.5 m/s | 1% | 0.74950 / 0.75080 / 1.49466 |
| 4 | 弧顶合速度 | 3√5/4 = 1.6771 m/s | 1% | 1.67263（-0.27%） |
| 5 | 碰后车+物块 x 动量 | 3.0 kg·m/s，波动 < 2e-3 | 绝对 | 2.99950，波动 3.0e-4 |
| 5 | 能量账 gap | ≤ 初能量 0.5% | 绝对 | -0.0112 J = 0.096% |
| 6 | run() 用时 | ≤ 4 s | — | 0.86 s（普通场景 ≤ 1.5 s，实测 0.03~0.35 s） |
| 7 | 确定性 | 两次逐帧完全相等 | 严格相等 | 相等 |

「生热到 1 J 那一刻」的取法（验收脚本里就是这样算的）：生热速率在物块滑到粗糙段尽头时被截断，
所以取倒数第二段完整粗糙段（1.140 s→1.145 s，速率 2.56 W）的速率外推：
t* = 1.145 + (1.0-0.99130)/2.56 ≈ 1.14836 s，再用同一段的小车/物块速度斜率外推。
**不要**去找 heat >= 1.0 的帧（全程只到 0.99990，会越界），也不要按世界坐标积分相对位移
（碰撞跨在两帧之间，会把第一段算漏）。

弧顶的竖直速度**用最高点高度反推**：vy = √(2g(y_top - 0.325))，y_top 取物块帧 y 的最大值
（实测 0.43670，理论 0.4375）。同时断言「离开圆弧后物块和小车的水平速度差 ≤ 0.02 m/s」，
防止实现成提前脱轨还能把错误藏进顶点高度里。

### 6.4 帧与汇总值的新字段（协议第 1 节的实现）

- frames[] 在旧键（t / x / y / vx / vy / speed / on / bodies）之外新增：
  plates=[[x, y, vx, vy, 角度度]]、wheels=[[x, y, 角度度, vx]]、springs=[[长度, 弹力]]、
  heat（累计摩擦生热 J）。旧场景一个键都不多（走旧路径）。
- values 在旧键之外新增：plates_end=[[x, y, vx, vy]]、wheels_end=[[x, y, 角度度, vx, omega]]
  （omega 是增补，方便验 v=ωR）、spring_energy、spring_loss。
- 扩展场景 force_keys=[]（不出力矢量）；forces 只有旧场景 scene.forces=true 才有。
- 事件 kind 仍用旧词表 on / leave / stop / land / bump / gone；扩展路径只会发
  on / hang / spring / roll / bump / gone（hang 开始悬挂、spring 弹簧开始受力、roll 轮子开始滚）。
- 图像记号新增：x小车 / v小车 / a小车 / v物块1 / v轮子1 / E弹s1 / Q，以及前缀
  E弹 / F弹 / 长 / 转角 / 角速度。y 表达式可以用分号写多条曲线："v(摆球); v(物块)"。

### 6.5 协议没写死、实现时定下来的地方

1. links 的 b 和 anchor **同时给** = 绳绕过定滑轮的连接体（约束 |A-P| + |B-P| = length）；
   协议只写了单摆（b=null + anchor），这个用法是引擎加的扩展，界面画成两条虚线到悬挂点。
2. links.length 可以不写（或写 0）：按初始几何补齐并回写到场景里（界面要显示长度）。
3. wheels[].plate：轮子跟板走是**运动学**的——中心 = 板位姿 + 局部偏移，速度取板在该点的速度，
   滚动角按「沿板不打滑」累计；轮子不反作用给板（协议原话「只是画法不改板动力学」）。
4. springs[].damping：阻尼力 F = k(d-rest) + damping·v_rel(径向)，阻尼耗散记进 values.spring_loss。
5. plates[].mu_ground：地面摩擦只作用在板的水平方向，法向力近似取板自重 M·g（没把板上物块的
   压力算进去，所以只在板单独滑动时准）。
6. rod 是双向距离约束；rope 只在拉直且两端分离时约束，松弛时没有张力。
7. 骑手离轨：物块沿轨道走到端点时，先找同一块板（或世界）上另一条「投影在段内、世界距离 ≤ 0.02 m」
   的轨道换过去；找不到就真的放开转自由运动（老师那道题的弧顶必须真的飞出去，不能一直贴在弧上）。
8. 老师原题里「撤去小球」之后的剧情（摆球摆回来追物块）不模拟：摆球碰后以 -3 m/s 往左摆回，追不上物块。
9. 旧路径完全没动：没有 plates / wheels / springs / links / anchors、并且轨道没有 body / arc 的场景，
   走的就是原来的 run()，10 条旧例子的数值一个都没变。
