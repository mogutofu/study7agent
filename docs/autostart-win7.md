# 开机自启动：学校一体机怎么设、怎么修

> 给老师看的说明。程序里已经有现成的诊断和一键修复，**先照着第 2 节点两下**，
> 再看诊断报告里的红字说的是什么（第 3 节）。
> 相关代码：`webui\core.py` 的 autostart 段（`autostart_command` / `autostart_state` /
> `autostart_diagnose` / `repair_autostart`），`webui\server.py` 的
> `GET /api/autostart`、`POST /api/autostart/repair`。

## 1. 这一版做了什么

开机自启有**三条路一起走**，任意一条活着就能起来：

1. **注册表启动项**（当前用户，不需要管理员）
   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
   值名 `Study7Agent`，数据是**带引号的命令行**：

   ```text
   "D:\程序目录\study7agent-1.1.0-beta11.exe" --autostart
   ```

   带引号是关键：程序装在**带空格的目录**里（比如桌面上「开学第一课」那个文件夹）时，
   裸路径写进启动项，Windows 只把空格前面那一段当成程序名，**开机一声不响地什么都不发生**
   ——老版本"没法开机自启"最常见的就是这一条。

   > **exe 的名字不一定是 `Study7Agent.exe`。** 单文件发布版叫
   > `study7agent-<版本号>.exe`（比如 `study7agent-1.1.0-beta11.exe`）。
   > 启动器启动服务时会用 `--exe-path` 把**正在跑的这一份**的完整路径告诉服务端，
   > 自启就指向它——所以升级换了文件名也会自动跟过去，不用重设。
   > （beta11 之前查的是固定名字 `Study7Agent.exe`，发布件里根本没有这个文件，
   > 于是"开机自启默认已打开"其实一次都没设上；这一版已经改掉了。）
2. **启动文件夹里的快捷方式**（兜底）
   `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Study7Agent.lnk`
   还原卡 / 希沃管家 / 360 把注册表那条清掉时，靠这个还能起来。
3. **程序自己会校正**：每次启动都会对一遍——程序被搬家了、注册表里还是老版本那种裸路径，
   它会把启动项改写成现在的位置；但**你手动关掉的自启它绝不偷偷开回来**（日志里会写改了什么）。

另外，**开机拉起来的那一份是安静的**：只显示屏幕右边那条**悬浮工具栏**，
不弹程序界面、不抢前台，所以开机后不会突然跳到讲台大屏中间挡住课件。
要用界面，点悬浮栏里的「显示界面」。

## 2. 怎么设（两部事）

1. 打开程序 → **设置** → 找到「开机自动启动 Study7Agent」那个开关，确认是**开**的。
2. 点旁边的 **「开机自启动诊断」**，等一两秒看下面出来的报告：
   - 结论是**生效**（绿色）就不用管了，重启一次就能验证；
   - 结论是红/黄，并且出现 **「一键修复」** 按钮 → 点它。
     它会：重写注册表启动项（带引号）、重建启动文件夹快捷方式、清掉任务管理器里的禁用记录，
     然后把每一项**回读一遍**确认真的写进去了。

> 用**老师平时登录的那个账号**做这两步。学校里常见"管理员账号装的程序、
> 老师用另一个账号登录"——开机自启写在当前用户的注册表里，**换个账号就不生效**。

## 3. 诊断报告怎么读

报告是一行一条，前面有颜色/等级：

| 结论 | 这一条在说什么 |
| --- | --- |
| **程序位置** | 它认为该自启的是哪个 exe（启动器传进来的真实路径，单文件版就是 `study7agent-<版本>.exe`）。只有"目录版/开发环境"（没收到 `--exe-path`，也没有 `Study7Agent.exe`）才会说"这一版不用设"。 |
| **路径里有空格** | 有空格不算错，但启动项**必须带引号**（这一版自动带）。红字说明当前那条是老写法。 |
| **注册表启动项** | 好 = 指向本程序且带引号；黄 = 指向本程序但是**老写法**（没引号 / 少了 `--autostart`），路径一有空格开机就静默失败；红 = 没有这一项，或者指向别处（程序被搬过家）。 |
| **启动文件夹快捷方式** | 好 = 有，且指向本程序；黄 = 没有（还原卡清掉注册表时就没兜底了）；红 = 有，但指向的不是本程序。 |
| **任务管理器 / msconfig 的禁用状态** | 红 = 这一项被「任务管理器 → 启动」或 msconfig 禁用过，**禁用了就算写了启动项也不会跑**。一键修复会清掉这条记录。 |
| **当前用户** | 写的是 HKCU，只对**这个登录账号**生效。不是管理员时会提醒：如果程序当初是管理员装的、老师用别的账号登录，那边不会生效。 |
| **可能清掉启动项的软件** | 粗查常见目录有没有**冰点还原（Faronics Deep Freeze）/ 希沃管家 / 360 / QQ管家**。有就提示：一键修好之后重启还是不启动，就让管理员加白名单，或者把程序放到**不受还原的分区**（一般是 D 盘，C 盘常被还原）。 |
| **上一次开机自启的日志** | 从 `logs\exe.log` 里翻出来的最后一条「开机自启」记录。**重启一次**之后这里应该出现新时间；一直不出现，说明开机那条路根本没走到（通常是第 3 节表格里红的那条没修）。 |

## 4. 学校一体机最常见的五种情况

1. **程序装在带空格的目录里，老版本写的是裸路径** → 开机静默失败。
   这一版会自动认出老写法并改写成带引号的命令行（诊断里那条"老写法"变绿）。
2. **程序装在 C 盘，机器装了还原卡/冰点** → 重启后 C 盘回到出厂，写进去的启动项也跟着没了。
   办法：把程序目录放到**不还原的分区**（D 盘），让管理员把程序加入白名单，或者每天开机后跑一次「一键修复」。
3. **用管理员账号装的、老师用另一个账号登录** → HKCU 写在管理员账号名下，老师的账号里没有。
   办法：用老师自己的账号登录，点一次「一键修复」。
4. **任务管理器 / msconfig 里被禁用过**（有时是学校统一策略、有时是误点）→
   一键修复会清掉禁用记录；也可以自己到「任务管理器 → 启动」里把它改成**启用**。
5. **360 / QQ管家 / 希沃管家拦截写启动项** → 注册表回读不一致时会提示"可能被杀毒软件拦了"。
   办法：临时退出这类软件再点一键修复，或者把它加进白名单。

## 5. 怎么自己验证（30 秒）

1. 设置里点「开机自启动诊断」→ 结论是**生效**。
2. **重启电脑**（或者注销再登录）。
3. 开机后**只出现悬浮工具栏**、出现程序界面了吗？没有界面是**正常的**（自启档不弹界面）。
4. 再打开设置点一次诊断，看**「上一次开机自启的日志」**：应该有刚开机那一次的时间和
   `--autostart` 字样。没有的话，看 `logs\exe.log` 里搜「开机自启」那几行说的什么。

## 6. 手动兜底（诊断也不行时）

- **启动文件夹**：按 `Win+R`，输入 `shell:startup` 回车，把程序目录里那个
  `study7agent-<版本>.exe`（目录版是 `Study7Agent.exe`）**右键 → 发送到 → 桌面快捷方式**，
  再把那个快捷方式拖进打开的文件夹。
- **注册表**：`Win+R` → `regedit` → 定位到
  `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，
  新建**字符串值** `Study7Agent`，数据填
  `"D:\程序目录\study7agent-1.1.0-beta11.exe" --autostart`
  （文件名照你程序目录里那个抄，**引号别丢**）。
- **看被谁拦了**：`msconfig` → 「启动」页；或者「任务管理器 → 启动」页。

## 7. 不想开机自启

设置里把「开机自动启动 Study7Agent」关掉即可：注册表那条和启动文件夹的快捷方式**两处都删**，
并且关掉之后程序**不会**在下次启动时偷偷改回来。

## 8. 换目录、升级之后要不要重设

不用。程序每次启动会对一遍自启路径：目录变了就改写到新位置，升级换了 exe 文件名
（`study7agent-1.1.0-beta11.exe` → `study7agent-1.1.0-beta12.exe` 这种）也会自动跟过去，
老版本留下的裸路径会补引号。
**前提是用 exe 本身启动**（exe 就在 `config\`、`data\`、`webui\` 旁边那一层）；
目录版（直接跑 `start-webui.cmd` / `python webui\server.py` 的开发方式）没有 exe，
自启按设计不设。
