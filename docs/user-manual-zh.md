# Study7Agent 中文操作手册

本文面向在 Windows 7 办公电脑上使用 `Study7Agent` 的用户。当前版本包含 EXE 正式版和 VS Code 插件版，用于连接公司内网 OpenAI 兼容接口，并提供聊天、文档处理、网页读取、办公 skills、本地记忆、模型切换和受控命令执行能力。EXE 版有时也被称为“单文件版”，目前仍在维护；欢迎针对任一版本提交 Issue，并向 `main` 分支提交 PR。

## 1. EXE 版安装

1. 获取 `agent-win7-x64.zip`。
2. 解压到普通用户可写目录，例如：

```bat
D:\tools\agent-win7-x64
```

3. 进入解压目录，复制配置模板：

```bat
copy config\agent.example.json config\agent.json
```

4. 编辑 `config\agent.json`，至少填写：

```json
{
  "base_url": "http://你的内网地址/v1/chat/completions",
  "model": "你的模型名称",
  "api_key": ""
}
```

5. 启动：

```bat
agent.exe chat
```

## 1.1 VS Code 插件版安装

Windows 7 只能使用 VS Code 1.70.x，建议固定安装 VS Code 1.70.3。

1. 获取 `win7-agent-vscode-0.4.4.vsix`。
2. 打开 VS Code。
3. 进入扩展面板，点击右上角 `...`。
4. 选择 `Install from VSIX...`，选中 `.vsix` 文件。
5. 安装后重启 VS Code。

也可以使用命令行：

```bat
code --install-extension win7-agent-vscode-0.4.4.vsix
```

在 VS Code 设置 JSON 中填写：

```json
{
  "win7Agent.baseUrl": "http://你的内网地址/v1/chat/completions",
  "win7Agent.model": "你的模型名称",
  "win7Agent.apiKey": ""
}
```

打开聊天：

```text
Study7Agent: Open Chat
```

VS Code 插件版支持聊天、模型切换、skills、记忆、当前项目读取、引用文件、引用 skill、文本文件、网页读取、命令执行、项目文件修改、回退修改和办公文档起草；对于 `docx/xlsx`，插件会调用随 VSIX 打包的 `agent.exe` 完成完整读写。

### VS Code 项目能力

聊天窗口按钮：

| 按钮 | 说明 |
| --- | --- |
| `Project` | 读取当前 VS Code 打开的项目，把项目下的文本文件加入上下文 |
| `Ref File` | 选择并引用某个项目文件，会在输入框插入 `@file:路径` |
| `Skill` | 选择并引用某个 skill，会在输入框插入 `@skill:名称` |
| `New` | 新建会话，当前会话自动保存在历史会话中 |
| `Sessions` | 切换历史会话 |
| `Rename` | 修改当前会话标题 |
| `Delete` | 删除某个历史会话 |
| `Rollback` | 回退上一次由插件应用的项目文件修改 |

也可以手写引用：

```text
请参考 @file:src/app.js 修复这个问题
请使用 @skill:report 帮我整理项目周报
```

连续工作模式：

1. 直接输入任务，例如“阅读当前项目并修复配置加载问题”。
2. 插件默认以连续工作模式运行，没有固定步骤上限。
3. 插件会自动把项目上下文交给模型，并在模型给出文件修改计划时应用修改。
4. 每次应用修改都会保存回退点。
5. 需要停止时，在聊天输入框内连续按两次 `Esc`，会立即中断当前模型请求或正在运行的命令。

聊天消息会把正式回答和辅助内容分开。正式回答默认展开，`Think`、`Agent Action`、`Agent Files` 等内容默认折叠，点击标题可以展开查看。

文件修改格式由模型自动输出，形式如下：

````text
```agent-files
{"summary":"修改说明","changes":[{"action":"write","path":"src/app.js","content":"新内容"}]}
```
````

支持的文件操作：

- `create`：新增文件，目标已存在时拒绝。
- `write`：写入完整文件内容。
- `replace`：在现有文件中精确替换一段文本。
- `delete`：删除项目内文件。

安全边界：

- 只允许相对当前工作区的路径。
- `../`、绝对路径、盘符路径会被拒绝。
- 项目扫描会跳过符号链接，文件修改也不能沿符号链接写出工作区。
- 默认跳过 `.git`、`node_modules`、`dist`、`build` 等目录。
- 默认只读取常见文本文件，跳过二进制和过大的文件。
- 回退只针对插件应用过的文件修改。

### VS Code 会话管理

插件版支持多会话，每个会话的对话历史和上下文相互隔离。

常用命令：

```text
Study7Agent: New Session
Study7Agent: Switch Session
Study7Agent: Rename Current Session
Study7Agent: Delete Session
```

说明：

- 点击 `New` 会创建一个空白新会话，当前会话会保留在历史会话中。
- 点击 `Sessions` 可以切换到历史会话。
- 点击 `Rename` 可以更改当前会话标题。
- 点击 `Delete` 可以删除指定历史会话及其上下文。
- `Clear` 只清空当前会话，不影响其他历史会话。

## 1.2 Web UI 版安装与使用

Web UI 版是在浏览器里使用的本地控制台，**不需要安装任何依赖**：它只用解压目录里随包的
Python 3.8.10（`python\python.exe`）和同一个目录里的 `agent.exe`，界面资源全部随包提供，
不访问 CDN、不需要 npm 构建，适合完全离线的内网办公机。

启动：**双击解压目录里的那个 exe（单文件版是 `study7agent-<版本>.exe`，源码运行版是 `Study7Agent.exe`）**，就这一个动作。

- 不会有黑窗口；服务在后台起来，界面以**独立的程序窗口**打开（不是浏览器里的标签页），
  任务栏上是单独一项，关掉它不影响你自己开着的其它网页。
- 屏幕右下角托盘里有一个 Study7Agent 图标（`agent.ico`），右键是：
  **打开界面 / 打开工作区 / 重启服务 / 查看日志 / 退出（连服务一起关）**；双击图标 = 打开界面。
- 不小心双击了两次不会开出两个程序：第二次只是把已经打开的界面窗口切到前台。
- 想全部关掉：右键托盘图标 →「退出（连服务一起关）」，服务、悬浮工具栏、界面窗口一起关。
- 第一次双击时，界面窗口要等十几秒才出来（那个窗口的浏览器配置目录是新建的）；
  之后再双击就快了。等待期间屏幕中间有一个「正在启动 Study7Agent…」的小黑条，属正常。

还是习惯老办法（或者想看着日志）就用控制台那条路：

```bat
start-webui.cmd
```

启动后控制台会打印模型、接口、工作区与地址，并自动打开浏览器（默认 <http://127.0.0.1:8770>）。
停止服务：在控制台窗口按 `Ctrl+C`。

### 悬浮工具栏（屏幕右边那条小工具条）

0.6.0 起，启动时屏幕右边会出现一条置顶的小工具条（`scripts\study7agent-float.ps1`）。
它用的是 Windows 7 自带的 PowerShell + .NET，**不需要装任何东西**。不想用它，
把 `--no-float` 加在启动命令后面即可。

- **点最上面那条彩色标题栏（或收起后的那个图标）= 只展开 / 收起工具条本身，不会把程序切到前台。**
  要打开程序界面，点工具条里的 **「显示界面」** 按钮——这是唯一入口（顶栏和图标现在只当拖动把手）。
  按住标题栏还能把它拖到别的地方，拖不出屏幕。
- **点右上角「收起」** = 缩成屏幕右边一条很窄的小条（图标 + **当前时间** + 展开 + 退出），
  不再挡视野；点「展开」就恢复。**收起一次以后会一直记着**，下次开机还是收着的。
- **点「退出（连服务一起关）」** = 网页、Web UI 服务、控制台窗口、工具条一起关掉。
- **关掉网页 = 自动全关**：网页每 2 秒跟服务打个招呼，关页面时会主动说一声，
  工具条在几秒内把服务和它自己一起收掉。按 `F5` 刷新不会误伤（新页面马上又会打招呼）。
- 工具条上的按钮**不是另一套功能**，每一个都调的是网页里那套：

| 按钮 | 做什么 |
| --- | --- |
| 希沃白板 / 希沃展台 / QQ | 打开这些外部软件，**并把它切到最前面**（已经在跑的也会被拎到前台） |
| 切到PPT | 分两种情况：**已经在放课件**就把它切到最前面（不打开文件、不读硬盘，点下去立刻切）；**一个都没开**就用默认应用（通常是 WPS 演示）打开**最近收到的那份课件** |
| 计时 | 网页上弹出计时窗口：点 1/3/5/10/15 分钟或自己填秒数，倒计时显示在大屏上 |
| 抽学号 | 随机抽一个**这一轮还没抽到**的学号，结果显示在大屏上 |
| 截图给AI | 截当前屏幕，并把图片直接放进提问框上方「待发送的图片」里——接着打字问它就行 |
| 板书保存 | 把当前屏幕存成图片，放在 `工作区\板书\` 下 |
| 课堂标记 | 记一个课堂时间点：当前时间 + 当屏截图，清单在 `工作区\课堂时间点.json` |
| 数学函数 / 几何画板 | 打开**作图面板**（见下），在面板底下直接写表达式就出图，也可以写一句话点「让 AI 画」 |
| 回到桌面 | 把所有窗口最小化，回到桌面（工具条自己不会被收走） |

**找不到课件怎么办**：**在网页的「设置」里就能填**——打开设置，找到「悬浮工具栏」那一段，
把 QQ 的下载文件夹填进「QQ 收到的文件放在哪个文件夹」。QQ 里能在
「设置 - 基本设置 - 文件管理」看到它当前的下载目录，照着填进去即可。
填了之后就**只在这个文件夹里找**最新的一份课件（`.ppt/.pptx/.pps/.ppsx` 都认）。

不填的话它会去猜几个常见位置（`文档\Tencent Files\...`、系统下载目录）——
新版 QQ 的下载路径存在它自己的数据库里，外面读不到，所以**猜不中时请自己填一下**。

同一段里还能填希沃白板 / 希沃展台 / QQ 的程序路径（留空就自动查找）。
这几项都存在 `config\float.json`，不进发布的包，改完立刻生效、不用重启。
也可以直接编辑那个文件：

```json
{
  "qq_download_dir": "D:\\QQ文件",
  "apps": {
    "whiteboard": "D:\\希沃\\EasiNote5\\EasiNote5.exe"
  }
}
```

### 作图面板（函数图像 / 几何图形）

数学课要画函数、几何课要画图形，现在**直接画在网页上**，不用再开希沃白板：

- 顶栏的「**作图**」按钮，或者工具条的「数学函数 / 几何画板」，打开作图面板；
  面板**底下就有一行输入框**，写函数点「画出来」立刻出图；
  **你也可以直接说"画个图"，AI 会自己画到这块面板里**（它被明确要求用这个工具，
  不会再去开希沃白板）；
- **函数图像**：写关于 x 的表达式，例如 `sin(x)`、`x^2 - 2x - 3`、`2x+1`，
  可以用 `sin cos tan sqrt abs ln log exp` 这些函数和 `pi`；
- **几何图形**：点一下「几何」，分号隔开一条条写，例如

  ```
  A(0,0); B(4,0); C(0,3); poly A B C; angle A B C; circle O 2; O(2,2)
  ```

  意思是：定义三个点、连成三角形、标出 ∠ABC、再画一个以 O 为圆心半径 2 的圆。
  也可以用 `线段 A B`、`直线 A B`、`圆 O 3` 这样的中文写法；
- **也可以直接在面板上让 AI 画**：输入框里写一句话（"画一个底 4 高 3 的直角三角形"），
  点「让 AI 画」——这句话会当成一次普通提问发出去，AI 画好之后**图会出现在同一块面板里**。
  面板上会告诉你它画到哪一步了：**蓝点 = 正在思考**、**绿点「画好了」**、
  **黄点 = 这一轮没画**（那就在旁边的对话里看它说了什么）。不会让你干等着猜。
  画完**不会把你的窗口弹到最前面**（你正在看别的程序时不会被打断）；
- 图上的坐标都是本机算出来的，不是猜的：曲线平滑、该断的地方会断开（比如 `1/x` 画成两支），
  几何图形保持等比（直角真的是直角）；
- 想改横轴范围、或者逐行写图形，点面板右上角的「更多设置」。

### 课堂资料在哪

顶栏「**课堂资料**」按钮里能看到三个目录各有几个文件，点「打开文件夹」直接用资源管理器打开：

| 目录 | 里面是什么 |
| --- | --- |
| `工作区\板书\` | 点工具条「板书保存」存下来的整屏图片 |
| `工作区\课堂时间点\` | 点「课堂标记」记下的每一张截图；时间清单是工作区里的 `课堂时间点.json` |
| `工作区\截图\` | 点「截图给AI」存下来的图（同时也会放进提问框的待发送图片里） |

**找不到希沃白板 / 展台 / QQ 怎么办**：工具条会告诉你没找到，并让你把它的 exe 路径填进
`config\float.json`（这个文件默认不存在，自己新建即可）：

```json
{
  "apps": {
    "whiteboard": "D:\\希沃\\EasiNote5\\EasiNote5.exe",
    "display":    "D:\\希沃\\SeewoDisplay\\SeewoDisplay.exe",
    "qq":         "D:\\腾讯\\QQ\\Bin\\QQScLauncher.exe",
    "powerpoint": "D:\\WPS\\office6\\wpp.exe"
  }
}
```

路径里的反斜杠要写两个（`\\`）。填完**不用重启**，下一次点按钮就生效：
先看这个文件，没填或填的路径不存在时才去自动查找（常见安装目录、开始菜单和桌面的快捷方式名字）。

首次运行会自动在桌面创建带图标的快捷方式「Study7Agent」，并给解压目录设置文件夹图标
（图标文件是 `agent.ico`，里面 16/24/32/48/64/128/256 七个尺寸都是**单独画的**，
小尺寸专门简化过，所以在任务栏和资源管理器里都不会糊；想换成学校自己的图标，
把新 PNG 命名为 `agent-icon.png` 后运行
`python\python.exe scripts\make-icon.py agent-icon.png agent.ico`）。
注意：`agent.exe` 这个命令行程序**内部**自带的图标是打包时嵌进去的，换 `agent.ico` 不会改变它。

**步骤折叠栏（思考 + 工具调用）**：

- 一次提问产生的思考与连续工具调用**合并成一个折叠栏**，最终回答显示在折叠栏之外。
- 生成中自动展开，标题显示「思考中…」并有旋转图标；调用工具时标题变成「调用 read_file…」。
- 生成结束自动折叠，标题变成「思考过程」，右侧显示「N 步 · 12.4s」。
- **你手动点过之后就不再自动折叠**：手动展开的不会被自动收起，手动折叠的也不会被自动打开。
- 模型在调用工具前说的过渡话属于回答本身，会按顺序接着往下写，工具调用不会把消息切成几段。
- 思考内容两种来源都支持：模型的 `reasoning_content` 字段，或写在 `<think>…</think>`
  （也支持 `<thinking>` / `<reasoning>` / `<thought>`）里的内容；回答里不会残留标签。

**推理等级（顶栏，模型选择器旁边）**：

- 默认 / 最省 / 低 / 中 / 高 五档，**按会话记住**：切回这个会话还是上次选的等级。
- 越高想得越久、越周密，也越慢、思考 token 越多：日常问答用「低」，出题写教案用「中」，
  整套课件、跨多个文件核对用「高」；「最省」适合翻译、改写这类有明确答案的活。
- 选「默认」= 不改动接口参数，沿用接口和模型自己的行为（设置页可以定新会话的默认档）。
- 右下角「本次运行」显示这一轮**实际生效**的等级；如果接口不认这个参数，会自动去掉重试并在对话里说明。

**一条连续的消息，以及「继续生成」**：

- 一次提问只有**一条**助手消息：上面是折叠栏（过程），下面是一整条正文，中途不会清空重画。
- 回答被长度上限截断、或者模型一个字都没写时，会自动接着写（最多 3 次），并在消息里留下说明。
- 熔断、工具轮次用尽、连撞多次长度上限、你按 `Esc` 停止——这些“没写完”的情况会在消息底部给一个
  **「继续生成」**按钮：点一下就接着写，不用自己打字说“继续”。标记存在会话里，刷新页面后按钮还在；
  你自己再提一个新问题后，上一轮的按钮会自动消失。

可选参数：

```bat
start-webui.cmd --port 8899        指定端口
start-webui.cmd --no-open          启动后不自动打开浏览器
start-webui.cmd --verbose          打印访问日志
```

界面组成：

- 左侧：历史会话（新建 / 搜索 / 重命名 / 删除），每个会话的历史与上下文相互隔离。
- 中间：对话区，支持流式输出、Markdown 表格与代码块、代码一键复制、重新生成。
- 输入区：文件 / 图片 / 页面 / 命令 四个按钮，`Enter` 发送、`Shift+Enter` 换行、`Esc` 停止；
  也可以直接把文件或截图**拖进**输入框，或者截图后 `Ctrl+V` 粘贴。
- **文件选择器怎么用**：顶上一条**面包屑**显示当前在哪（`C:\ › 用户 › 老师 › 桌面 › 第三课`），
  点任意一段就能跳过去；下面是常用位置（桌面 / 文档 / 下载 / 图片 / 工作区）和各个盘符。
  再往下是「上一级 / 刷新 / 全部·文档·图片 / 搜索框 / 从电脑选择文件」。
  列表里**单击选中、双击进入文件夹或直接确定**；按住 `Ctrl` 可以**多选**，右下角会显示
  「已选：文件名」或「已选 N 个」。键盘：`↑``↓` 移动、`Enter` 进入或确定、`Backspace` 回上一层。
  切到「只看图片」时小图会显示缩略图；如果筛选后没有匹配，会告诉你「另有 N 项被筛掉」而不是空白。
- 设置入口：顶部工具栏最右侧的齿轮按钮，或左侧栏底部的“设置”按钮。
- 右侧：本次运行的轮次、耗时、token 用量、**上下文缓存命中率**、费用估算、工具时间线。

浏览器要求：

- 推荐 Chrome / Edge 109 及以上，或 Firefox 115 ESR。
- 360、QQ、搜狗等双核浏览器**必须使用极速模式**（页面已声明 `renderer=webkit`，通常会默认用极速模式）；
  兼容模式是 IE 内核，不支持流式对话。若落入兼容模式，页面会直接提示切换方式。
- IE 11 不支持。
- 界面图标使用内联 SVG 绘制，Windows 7 缺少 emoji 字体也能正常显示。

文件读写范围：

- 默认允许读写工作区之外的任意绝对路径（`D:\`、桌面、共享盘等），模型可以直接编辑这些文件。
- 只想让它改工作区内的文件时，在设置里取消勾选“允许读写工作区之外的路径”；
  系统提示词会跟随该开关变化，权限放开时模型不会再反复索要授权。
- 每次覆盖写入前都会自动保存快照，右侧“快照”按钮可一键回滚。

为 DeepSeek 做的适配：

- 使用原生 `tools` / `tool_calls` 协议调用工具，不再依赖 `agent-action` 文本约定。
- 单独展示 `reasoning_content` 思考过程，并且不会把思考内容回传下一轮。
- 读取 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens`，实时显示缓存命中率与费用估算。
- 系统提示词保持稳定前缀、工具定义顺序固定，减少前缀缓存失效。
- 设置页可一键拉取接口的真实模型列表，并查询账户余额。
- `base_url` 支持裸域名、`/v1` 结尾或完整 `/chat/completions` 三种写法。

课堂互动与学习闭环（一体机上课最常用的几个动作）：

- **抽学号/分组**：`pick_students`。默认在 **1-50 号**里抽，不需要任何名单文件；
  抽过的学号本轮不再重复，抽完一轮自动重开；班级人数不是 50 时用 `max_number` 指定；
  `mode="group"` 可以全班随机分组。抽到谁就投大屏显示"请回答：学号 12"。
- **右侧详情栏**：显示本次运行（状态/模型/轮次/技能/Token/费用）、**思考链路**（实时显示模型的思考过程）
  和**工具调用**（名称、关键参数、耗时）。
- **课堂计时**：`class_timer`。大屏显示倒计时胶囊，时间到自动响铃，适合小组讨论、限时练习。
- **投屏讲评**：`show_on_screen`。全屏大字显示题目/答案/要点/主题，字号按教室后排可读设计；
  一次只投一屏，关闭后再投下一屏。
- **错题本**：`mistake_book`。按知识点记录错题（题目/答案/错因/学生），`stats` 看哪个知识点最薄弱，
  `practice` 生成重练卷（题目在前、参考答案另起一页、附错因提示）；练习过的题会被标记，下次优先出没练过的。
- **成绩统计**：`score_stats`。平均分、中位数、标准差、及格率、优秀率、分数段分布都由代码精算，
  不会出现心算错误；可另存 xlsx 汇总表；默认不列学生个人分数。
- 配套技能：`classroom`（一节课的节奏与每个环节该用哪个工具）、`flashcards`（复习卡）、
  `tiered-homework`（基础/提高/拓展三档分层作业）、`explain-simply`（怎么把概念讲到学生听懂）、
  `socratic`（用追问把学生引到答案上）、`error-analysis`（错题归因与补救练习顺序）、
  `doc-to-questions`（课件/文档变三层随堂问题）、`parent-report`（给家长的一段反馈）、
  `report`（成绩与学情报告的写法）。

内置工具：`list_dir`、`read_file`、`write_file`、`run_command`、`read_url`、`view_image`、
`web_search`、`pick_students`、`class_timer`、`show_on_screen`、`mistake_book`、`score_stats`、
`run_subagent`。

识图（需使用支持图片的模型，如 `deepseek-flash`）：

- 三种发图方式：截图后在输入框 `Ctrl+V` 粘贴、点「图片」按钮在图形化选择器里点选、拖拽图片文件到输入框。
- 选择器里有盘符与「桌面 / 文档 / 下载 / 图片 / 工作区」快捷位置，可以逐层点选，**不需要手打路径**。
- 支持 `png/jpg/jpeg/gif/webp/bmp`，单张不超过 8MB；**一条消息默认最多 256 张**
  （设置 → 自我修改与安全边界里的「单条消息最多注入几张图片」，`max_images`，1–2000 可调）。
- 一摞卷子照片可以一次性全丢进来；总量还有 24MB 的字节预算兜底，超出的张数和原因会在对话里如实说明，
  不会悄悄少给几张。
- 模型也能自己看图：`list_dir` 里发现的照片可以让它用 `view_image` 打开（图片会注入下一轮请求）；
  工具读图注入同样受张数上限约束，到顶会提示一次。
- 图片按图片 token 计费，历史里只保留最近两轮的图片，更早的会自动省略。
- `deepseek-v4-pro` 不支持图片，会回复“无法查看这张图片”，此时界面会提示切换到 `deepseek-flash`。
- 典型用法：拍学生作业 → 批改并生成讲评课件；截课本页面 → 按知识点出练习题；发成绩表截图 → 整理成成绩表。

思考过程的显示：

- 左侧对话里，**一段连续的「思考 + 工具调用」合并成一个折叠栏**；思考在折叠栏里只占**一行**，
  新思考不断往右推、容器自动滚动，所以最新的想法一直可见，折叠栏高度恒定，页面不会跳来跳去。
- **点那一行即可展开完整思考**（可上下滚动），再点收起；历史消息里的思考同样能展开回看。
- 右侧详情栏的「思考要点」是服务端边流边提炼的**要点**，与左侧折叠栏的全文相互独立。

工作区与对话列表：

- 左侧栏从上到下是：品牌行（名称 + 版本 + 收起）、**新会话**、**技能中心**、
  **「工作区 · 当前目录名」标题行**（右侧三个小图标：搜索对话 / 只看本工作区 / **新建工作区**）、
  **按工作区分组的对话列表**、底部快照与设置。
- **新建工作区（会真的建一个文件夹）**：点标题行最右边的「文件夹+」打开**工作区对话框**：
  上半是**已有工作区列表**——每行显示名字、完整路径和对话条数，当前那个带「当前」标记，
  **点一行就切过去**，行尾图标是在资源管理器中打开它；下半是新建：填名称（就是文件夹名），
  位置默认在安装目录的 `workspaces` 里（点「换个位置…」可以选 D 盘、桌面、共享盘），
  下面会**实时显示最终建出的完整路径**：名称里有 `\ / : * ? " < > |` 时当场提示「已自动去掉」并禁用按钮，
  有同名工作区会提示「另有一个同名工作区」，已经是工作区的目录会说明「会直接切过去用它」。
  点「新建并进入」后文件夹建好、登记进侧栏、切为当前工作区，并在里面开好一个对话。
  想把已有文件夹收进来，用「添加已有文件夹…」（会打开文件选择器的文件夹模式，按钮写着「用这个文件夹」）。
- 工作区那一行左边是文件夹图标和名字，右边是对话条数；**当前工作区默认展开**（名字加粗、文件夹图标高亮），
  别的收着。**点别的工作区那一行 = 选中它**（工作区真的切过去，顶部路径会变），它下面的对话直接点开就行；
  点当前工作区那一行则是收起/展开它的对话。一行对话显示**标题 + 相对时间**（10 分钟 / 昨天 / 03-14），
  鼠标移上去出现重命名和删除；触摸模式下这两个按钮一直显示。
- **在工作区下面新建对话**：点那一行右侧的「**+**」（提示是“在‘某某’中新建对话”）；也可以先切过去，
  再用顶部的大按钮「新会话」。
- **工作区行的「⋯」菜单**：重命名工作区（只改显示名，不动文件夹；重名会提示）/
  在资源管理器中打开 / 从工作区列表移除。
- **从列表移除只是移除登记**：文件夹和会话记录都保留，它的对话会显示在侧栏的「**未分组**」下面，
  点开照样能继续用；想收回来再用「添加已有文件夹…」。
- 没对话的工作区：新建/添加过的照样占一行（否则没法在它下面建对话）；从没登记过的空文件夹不占行，
  当前工作区名一直显示在「工作区」标题上。
- 打开属于其它工作区的对话、或者重启后恢复上次的对话时，工作区都会自动切回去（界面会提示），
  AI 就会把文件写回原来的位置。
- 两个文件夹重名时会补上父目录名（`高一\课件` / `高二\课件`）；同一个目录写成 `D:\课件`、`d:/课件/`、
  末尾多个 `\` 都算一个工作区，不会在侧栏里显示成两行。
- 「筛选」图标在「显示全部工作区 / 只看本工作区」之间切换；在搜索框里输入内容时，会跨所有工作区平铺结果。
- 界面只有中间的对话区滚动，顶栏和左右侧栏固定不动；对话很长时右下角有「最新」按钮。

子代理（分派干活）：

- 模型可以把相对独立的子任务派给子代理（`run_subagent`），一轮里派多个会**并行执行**。
- 子代理有独立上下文与受限工具集（不能再派子代理），默认最多 256 轮工具调用；
  一次运行最多 4 个（两项都能在设置里改）。
- 两处都能看到子代理：对话里是一张卡片（角色、任务、内部每一步工具调用、返回的结论）；
  **右侧「子代理」栏**会实时列出正在工作的子代理——标题上写着"几个正在工作"，
  每个显示角色、当前执行的那一步、已走多少步、跑了多久，结束后标成"已完成/失败"和耗时。

熔断（防止思考打转）：

- 连续重复同样的动作 3 次 / 单轮思考超过 6 万字会停止并给出提示，避免一直消耗 token。
  两个阈值都能在设置里改。
- **单次运行时长默认不限制**（`max_run_seconds = 0`）：画一整套课件、批量整理一学期的资料这类活
  本来就慢，不再用墙钟时间掐断；要限制就在设置里填秒数（例如 `900`）。
  真正兜底的是"上下文自动压缩 + 重复动作提醒 + 手动停止按钮"。
- 重复判定不会误伤"画一笔、截屏看一眼"这类操作：只读工具（截屏、列窗口、读文件、读剪贴板、搜索）
  连续调用不算重复，很短的回复（"好的""继续"）也不算；只读且幂等的工具不会触发熔断。
- 工具轮次上限默认 1024（设置里可改，最大 8192），用尽时会明确说明"这一轮的工具调用没有执行"，
  并留下「继续生成」按钮接着做，不会只丢下半句话就结束。

文件与命令上的“坑”是怎么处理的（中文 Windows 7 上真会遇到）：

- **中文编码**：记事本存的“Unicode”(UTF-16)、WPS 导出的 GBK、VSCode 的 UTF-8（带/不带 BOM）都能正确读；
  读到一半被截断也不会把整段中文变成问号。成绩表 CSV 用的是同一套解码规则。
- **文件名**：写到 `CON.md`、`COM1`、`第三课:函数的单调性.md` 这类 Windows 不允许的名字时，
  会直接告诉你哪儿不对、该怎么改，而不是抛一句系统错误。
- **长路径**：Windows 7 路径上限 260 字符；读写会自动用 `\?\` 前缀绕过，超长时也会提示换目录。
- **文件被占用**：Word/WPS 正开着这个文件时，会提示“先关掉它再试”，而不是报参数错误。
- **命令**：超时会连它的子进程一起结束（不会留下后台程序占着电脑）；
  用 `^` 转义、`start`、`for … do` 等写法绕开确认框的招数已经堵上；
  审计日志写不进去时会在结果里说明。
- **同一个对话**同时只能跑一个：两个窗口一起提问时，第二个会提示“正在生成中”，不会互相覆盖记录。
- **浏览器休眠/关掉页面**：写不出去就自动取消这次运行（默认 30 秒，可在设置里改 `sse_write_timeout`），
  不会一直挂着占住对话。
- **局域网访问**（例如用平板遥控教室电脑）：把监听地址改成 `0.0.0.0` 后，程序会自动生成访问令牌，
  命令行里给出带令牌的地址；没令牌的请求一律拒绝。

联网搜索：

- 模型需要外部资料时会用 `web_search`；内置 Bing 与 DuckDuckGo，Bing 优先用结构稳定的 RSS 输出。
- **完全离线的内网**可以在设置里填单位自建的搜索接口，例如 `http://intranet/search?q={query}`，
  返回 JSON 或普通 HTML 结果页都能解析。
- `fetch_top` 可以一次把前 1-3 条结果的正文节选一起取回；`read_url` 一次最多读 3 个链接。
- 百度、搜狗的网页有反爬，没有内置；DuckDuckGo 在部分网络下不可达会自动跳过。
- 搜不到时模型会如实说明，不会编造链接。

工作区：

- 默认工作区是解压目录下的 `workspace\`，服务启动时自动创建。
- AI 新建的文件默认写在工作区里；只说文件名也写到这里，只有你给出别的路径时才写到别处。
- 顶部「工作区」按钮：选择文件夹（图形化点选）、在资源管理器中打开、查看工作区里的文件并一键打开
  （`.exe/.bat` 等可执行文件不允许从界面直接运行）。
- 上传的图片与文件统一放在 `工作区\.webui-uploads\`。

技能（Skills）：

- 顶部「技能」按钮打开管理面板：列出全部技能，勾选后本会话每次提问都会带上（按会话保存）。
- 可以在面板里新建、修改、删除技能，保存后立即生效，不需要重启。
- 没勾选的技能也会按你的说法自动带上（例如“出 10 道练习题”会带上 `quiz`）；
  内置教学技能声明了 `keywords`，命中更准；右侧「运行详情」显示本次实际带入的技能。
- 技能文件格式：`skills\<名称>\SKILL.md`，可以写 `name` / `description` / `keywords` 三个字段。

教学场景（一体机上的常见用法）：

- 课件：`write_file` 写 `.pptx`，大纲写法是 `# 标题`（一页一张）、`## 小标题`、`- 要点`、
  `1. 步骤`、`| 表格 |`、`> 讲稿备注`、`--- 分页`。生成的课件是 16:9，
  标题 36pt / 正文 28pt，教室后排也能看清；`> ` 备注会另存为「课件名.讲稿.md」。
- 沿用学校统一模板：`write_file` 的 `template` 参数填模板 `.pptx` 绝对路径，
  新页面会追加到模板之后，并沿用模板的主题配色与母版。
- 改旧课件：先用 `read_file` 读回旧课件的文字大纲，改完再写回（覆盖前自动快照，可回滚）。
- 教案 / 试卷 / 通知用 `.docx`（支持标题层级、表格、列表、加粗），成绩表用 `.xlsx`
  （首行加粗并冻结）。
- 内置教学技能：`courseware`（课件规范）、`lesson-plan`（教案写法）、`quiz`（出题规范）、
  `grade-analysis`（成绩分析口径），输入里提到相关词会自动带上，也可用 `@skill:courseware` 显式引用。
- 顶部工具栏的“屏幕”按钮可切换**触屏模式**：放大字号与按钮，并让复制/重新生成等按钮常显，
  适合直接在一体机屏幕上用手指操作。

安全说明：

- 命令策略与命令行版一致：拦截前缀直接拒绝，高风险前缀在界面上弹窗确认后才执行。
- 每次覆盖写入前自动保存快照，界面上“快照”按钮可一键回滚。
- 文件工具默认只能读写 agent 所在目录（工作区沙箱），越界需在设置中显式开启。
- 服务默认只监听 `127.0.0.1`；若改为对外监听，必须设置访问令牌。

界面配置保存在 `config\webui.json`，与命令行版共用的模型、密钥、命令策略仍在 `config\agent.json`。
详见 [webui/README-zh.md](../webui/README-zh.md)。

## 2. 配置说明

配置文件路径：

```text
config\agent.json
```

常用字段：

| 字段 | 说明 |
| --- | --- |
| `base_url` | 内网 OpenAI 兼容接口地址，通常以 `/v1/chat/completions` 结尾 |
| `model` | 默认模型名称 |
| `active_model` | 当前启用的模型配置名，留空表示使用默认模型 |
| `models` | 多模型配置，用于 `agent.exe model use <name>` 或聊天内 `/model <name>` |
| `api_key` | API Key；如果内网网关不需要鉴权，可以留空 |
| `stream` | 是否启用流式输出 |
| `headers` | 调用模型接口时附加的全局 Header |
| `auth_profiles` | 内网页面的 Cookie/Header/Basic Auth 配置 |
| `command.enabled` | 是否允许本地命令执行，默认开启 |
| `command.confirm_prefixes` | 高危命令前缀，命中后需要人工确认 |
| `command.blocked_prefixes` | 永远拒绝执行的命令前缀，默认空 |
| `command.max_tool_rounds` | 单次用户请求最多连续执行的工具轮数，默认 1024 |
| `memory.enabled` | 是否启用本地会话记忆 |
| `memory.session_file` | 记忆保存文件 |
| `max_content_chars` | 文档和网页送入模型前的最大字符数 |

Web UI 自己的设置存在 `config\webui.json`（设置界面里改的就是这些；具体键名在界面上都有对应中文说明）：

| 字段 | 说明 |
| --- | --- |
| `max_images` | 单条消息最多注入几张图片，默认 256（设置界面可改，1–2000） |
| `confirm_high_risk_commands` | 高风险命令是否逐条确认，默认 `false`（直接执行） |
| `allow_self_restart` | 是否允许 agent 改完自己的源码后用 `restart_service` 重启生效，默认 `true` |

## 10. 本地命令执行

命令执行默认开启。**普通命令和高危命令都直接执行**，不再逐条弹确认框
（老师要的是"说一句就干完"，每次点一下鼠标很烦）；被 `blocked_prefixes` 拦下的命令永远无法执行，
这个硬拦截不受任何开关影响。

想恢复"执行前先问我"，在设置 → 自我修改与安全边界里勾上
「执行高风险命令（del / format / reg / powershell…）前先问我」（对应 `confirm_high_risk_commands`）。
勾上以后，命中高危前缀的命令才会先弹确认框。

默认会被**直接拦截**的前缀是 `blocked_prefixes`；社区版示例里高危前缀清单为：

```text
del, erase, format, reg, net, netsh, powershell, wmic, shutdown, sc, takeown, icacls, diskpart, cipher
```

示例配置：

```json
"command": {
  "enabled": true,
  "confirm_prefixes": ["del", "reg", "powershell", "shutdown"],
  "blocked_prefixes": [],
  "always_confirm": false,
  "audit_log": "logs/commands.log",
  "max_output_bytes": 65536,
  "max_tool_rounds": 8
}
```

模型请求命令后，CLI 会把命令输出、非零退出、拒绝或取消结果回传给模型，再由模型决定继续调用工具或给出最终答复。达到 `max_tool_rounds` 后不再执行新命令，并要求模型总结已有结果，避免无限循环。

执行命令：

```text
> /run dir
> /run findstr /s /i "error" *.log
```

如果命中高危前缀：

```text
High-risk command, confirm run? del temp.txt [y/N]:
```

建议：

- 不熟悉的命令不要确认。
- 可以把公司明确禁止的命令加入 `blocked_prefixes`。
- 复合命令中的每一段都会检查，例如 `echo ready && del temp.txt` 仍会触发高危确认。
- 命令审计日志默认写入 `logs\commands.log`。

## 10.1 电脑操作能力（Web UI 版）

Web UI 版可以直接操作这台电脑的"屏幕上的东西"，不用再教老师一步步点。全部能力可以一句话概括：

| 老师这样说 | 实际发生的动作 |
| --- | --- |
| "屏幕上这个弹窗是什么意思？" | `snapshot` 截屏 + 列元素 → 图片送给模型 → 模型看着屏幕回答（不是猜） |
| "投影没显示出来，你帮我看看" | `snapshot`（画面 + 所有窗口清单：哪块屏、哪个程序在前台） |
| "把希沃白板切到前面" | `app` 的 `switch`（切窗口到前台） |
| "那个广告窗口关掉" | `app` 的 `close`（默认直接关；勾了「动鼠标键盘前先问我」才会先确认） |
| "把这段评语打进去" | `type` 把文字输入到指定控件/窗口（中文走 Unicode 注入，不挑输入法） |
| "在白板上画一条横线" | `move(drag=true)`：移动鼠标 → 按住左键 → 沿轨迹拖到终点 → 松开 |
| "视频暂停一下 / 声音太大了" | `shortcut("play_pause")` / `shortcut("volume_down")` |
| "按 Ctrl+S 保存" | `shortcut("ctrl+s")` |
| "把记事本里的文件名改成第三课" | **按元素编号操作**：`snapshot` 拿元素清单 → `click(label=…)` 点输入框 → `type(text=…)` 填字 → `click(label=…)` 按「保存」 |

### 画图：一次调用画完一整幅（`draw_path`）

在白板或画图工具里画一个几何图形，如果一笔一次地调 `move(drag=true)`，**每画一笔都要一次模型往返**
（十几秒起步），画个正方体要等好几分钟——这是"工具执行太慢"最主要的原因。

现在有 `draw_path`：把整幅图（多笔、每笔多点）交给**一次**调用，中间分步移动
（白板靠轨迹成线），笔与笔之间抬起、移动到下一笔起点、停顿、再落笔，画完把鼠标放回原处。
画完建议 `screenshot` 确认一下，因为它不会替你判断画得像不像。

### 下载图片 / 文件 / 视频（`download` / `download_status`）

| 场景 | 怎么用 |
| --- | --- |
| 老师给一个图片地址 | `download` 直接下；图片会自动送进对话让你"看见"，可以直接讲内容 |
| 一节课要用的视频/音频 | `download` 下完顺手指一下编码（配合 `inspect_media` 判断这台 Win7 能不能播） |
| 几百 MB 的大文件 | `background=true` 放后台下，**不占用对话**；过一会儿用 `download_status` 看进度，下完它会主动说一声 |
| 网站防盗链 | 传 `referer`（来源页面地址） |
| 下错了 / 不想下了 | `download_status` 带 `action=cancel` 取消；已经下的部分会删掉，不留半截文件 |

限额与安全：单文件默认 200MB（可调，硬顶 2GB），超了会**如实告诉你截断到哪**；
服务器声明的长度超限时**直接拒绝**，不浪费时间下；落盘先写 `.part` 再改名
（Win7 上改名常撞"文件被占用"，会自动重试）；下到的如果是网页而不是文件，会明确说明。

### 按编号操作界面（快照 → 编号 → 动手）

鼠标点坐标在不同分辨率、不同缩放的机器上会偏，窗口一挪就点空。所以界面操作走"先看编号、再按编号动手"的路：

1. `snapshot`：一次拿到**窗口画面 + 可操作元素清单**。每个元素前面有个 `[编号]`，截图上的红字就是同一个编号。
   元素行上写着控件类型、名字、中心坐标、能做什么（fill 填字 / toggle 勾选 / select 选择 /
   slide 拖动 / scroll 滚动 / click 点击），以及能读到的值（输入框里的字、是否勾选、快捷键）。
2. `click(label=编号)` / `type(label=编号, text=…)` / `scroll(label=编号)`：按编号动手，
   坐标由程序**按当前界面重新算**——界面变了会退回快照坐标并明确告诉你"界面已变"，不会闷头点错地方。
3. 也可以直接给坐标（`click(loc=[x,y])`）：坐标是**屏幕物理像素**，来自刚截的那张图；
   窗口一挪就作废，会被"画面已经变了，请重新快照"挡下来（这是保护）。

**诚实说明（这一版换了实现，和以前不一样）**：以前那版能调 UI 自动化的 Invoke/Value 接口
"不移动鼠标、不抢焦点"地操作控件；这一版换了底座（ctypes 直连 + 常驻 UIA 工作进程），
**点击 / 打字 / 滚动 / 拖动都是真鼠标真键盘**——会移动你屏幕上的指针、会真的按键。所以：

- 能用命令行、文件、剪贴板、`app` 切窗口办成的事，模型会优先用那些（系统提示里这么要求）；
- 真要动鼠标，系统提示要求它先说一句"我要动你的鼠标点 XX"；
- 你正在用电脑时别让它连点；「动鼠标键盘前先问我」这个开关可以拦下每一次动作。

三条硬规矩（写在系统提示里，也是这么实现的）：

- **编号只属于这一次快照**：界面变了就重新 `snapshot`；按编号动手时程序会用"这个控件现在在哪"
  重算坐标，名字对不上就拒绝并说明，不静默点错。
- **不静默降级**：元素不支持某个动作就如实说，由模型自己决定下一步，不会偷偷换成别的做法
  （静默降级会让"看起来点了"和"真的点了"分不清）。
- **做完要从新状态里验证**：点下去不等于事情办成了，再 `snapshot` 一次看结果。

其它实现细节：`snapshot` 省略 `window` 就是整个桌面（元素清单也含所有窗口）；
给了 `window` 就只列那个窗口的元素，但**画面仍然是整个屏幕**（或你指定的 `region`）。
截图是"从屏幕上按矩形抓"的，所以**窗口被别的窗口挡住时，拍到的是挡在前面的东西**——
要看被挡住的窗口，先用 `app(mode="switch")` 把它切到前台。

已知限制（诚实说明）：

- **自绘界面拿不到元素**：Chromium/Electron、Qt、游戏这类程序常常只暴露一个空树，
  这时候会明确告诉你"没有可用的界面元素"，请改用 `screenshot` 看坐标 + `click(loc=…)` 点。
- **要管理员权限的窗口点不动**：普通权限运行的 agent 操作不了以管理员身份运行的程序
  （Windows 的 UIPI 限制，Win7 一样），会失败而不是假装成功。
- **快照有成本**：一次 `snapshot` 大约 0.3–0.8 秒（元素多时更久），元素很多时只列前 400 个
  （可用 `max_elements` 调大），被截断时结果里会写明。

设置里有四个开关（都在「设置 → 电脑操作 / 自我修改与安全边界」里）：

- **允许桌面操作**（默认开）：关掉后这一整组工具（含界面快照与点击）直接不可用。
- **动鼠标键盘这类操作前先问我**（**默认关**）：默认不弹确认框，说一句就干完；打开后点鼠标、打字、
  发快捷键（含多媒体键）、滚动、拖动、批量填表、关窗口、改剪贴板、结束进程、改注册表都会先弹一个
  写明"要做什么"的确认框（`snapshot` / `screenshot` 是只读的，不打扰）。
- **发邮件 / 推群 / 发 QQ 消息前先问我**（**默认关**）：打开后每次对外发送前先确认。
- **执行高风险命令前先问我**（**默认关**）：默认 `del`、`powershell`、`reg` 这类命令也直接执行；
  打开后才会弹确认框。`blocked_prefixes` 的硬拦截与这个开关无关，永远生效。

两个确认开关互相独立。**默认状态下模型可以直接动你的鼠标、也可以直接替你发消息**——把电脑借给别人、
或让模型跑不熟悉的任务时，建议把它们打开。

已知限制（诚实说明）：

- **需要有人已登录桌面**。如果这台机器锁屏或停在登录界面，截屏和鼠标键盘都用不了（会明确报错，
  不会假装成功）。
- **Win7 上第一次调用会慢一点**：界面元素那条路要先把常驻的工作进程拉起来（约 1 秒，之后一直复用，
  后续查询是毫秒级）；截图不需要进程，直接抓屏（1920×1080 约 40 毫秒）。
- **高 DPI（125%/150% 缩放）已处理**：截屏和鼠标坐标统一用物理像素，照着截图点不会偏。
- **输入中文不挑输入法**：直接用 Unicode 注入逐字送进去（不用切输入法、不占剪贴板）。
- **模拟操作 ≠ 万能**：窗口标题变了、弹了子对话框、程序没响应时可能失败。
  所有工具都会返回"实际做了什么"和报错原文，失败时请以截图为准，不要假定成功。
- **UI 自动化的边界**：自绘界面（Chromium/Qt/游戏）没有元素可枚举；以管理员身份运行的程序
  普通权限点不动。这两条都会明确报错，不会假装成功。详见上一节。

**这套做法参考了 DeepSeek Harness 的 computer use 约定**（先快照、按令牌操作、令牌随新快照失效、
动作后从新状态验证、失败不静默降级），但实现完全换成 Win7 上能跑的东西：PowerShell 2.0 +
系统自带的 UI Automation（.NET 3.0 的 `UIAutomationClient`），**不需要装任何第三方组件**。

## 10.2 自我修改：让 agent 改自己（改完自检再重启）

| agent 用的工具 | 作用 |
| --- | --- |
| `edit_file` | 按"原文 → 新内容"做精确替换（找不到原文时给出最接近的一行的提示，宁可不改也不乱改） |
| `self_check` | 跑一遍内置自检（`webui\test_webui.py`，约 5 分钟，不需要联网和密钥），通过才算改对了 |
| `restart_service` | 安排重启：先起一个独立小脚本，等当前进程退出后自动拉起 `start-webui.cmd`，几秒后刷新页面即可 |

推荐流程（系统提示里也是这么要求的）：

1. `read_file` 看清现状；
2. `edit_file` 小步替换（不要整文件重写）；
3. `self_check` 自检——**没通过就不要重启**，按报错继续修；
4. `restart_service`，`reason` 里写清改了什么（会记进 `logs\self-modify.log`）。

安全边界（写死在代码里，跟设置无关）：

- **始终禁写**：随包的 `python\` 运行时（改坏程序就起不来）、`webui\data`（你的对话记录）。
  此外 Windows/Program Files 等系统目录照旧禁写（`SystemRoot\Temp` 例外）。
- **允许改写**：安装目录下的 `webui\*.py`、`config\*.json`、`skills\*`、`docs\*` 等本程序自己的文件。
- 设置里的「允许 agent 改完自己的源码后自动重启服务生效」（`allow_self_restart`，默认开）
  关掉后，它仍然能改文件，但只能提示你手动重启。
- 每次改动源码前，`write_file`/`replace_media` 之类的写操作仍会留下可回滚快照（见侧栏「快照」）。
- 自检期间会强制设置 `W7A_NO_INPUT=1`：**测试绝不会去动你的鼠标键盘**。

如果它把自己改坏了：关掉窗口，删掉解压目录，重新解压一份包即可；
`config\` 和 `workspace\` 备份出来还能接着用。

### 11.1 让 agent 自己发邮件 / 推群消息（Web UI 版）

Web UI 版内置了三个"把消息送出去"的工具，配置一次就能一直用（设置 → 消息通知）：

| 通道 | 怎么配 | 适合什么 |
| --- | --- | --- |
| `send_email` | 填 SMTP 服务器、邮箱账号、**16 位授权码** | 发通知、成绩单、课件给同事和家长，可带附件 |
| `notify_webhook` | 粘一个群机器人 Webhook 地址 | 企业微信/钉钉/飞书群里立刻可见 |
| `send_qq_message` | 不需要配置（用本机已登录的 QQ） | 用 QQ 给当前聊天窗口发消息，发完自动截图 |

**QQ 邮箱特别注意**：设置 → 账户 → 开启「POP3/SMTP 服务」后拿到的那串 16 位**授权码**才是密码，
登录密码一定会认证失败。报错信息里会直接这样提示你。

**安全**：授权码和 Webhook 地址只存在本机 `config\webui.json`，界面上只显示掩码，
留空保存 = 不修改；所有对外发送都会先弹确认框，确认框里写着收件人和内容摘要。

`send_qq_message` 是**模拟操作**（切到 QQ 窗口 → 输入 → 回车），不是 QQ 官方接口：
需要 QQ 已登录、聊天窗口已打开；QQ 里设了"Ctrl+Enter 发送"时要用 `send_shortcut="ctrl+enter"`。
发完会自动截一张图，请以截图为准判断有没有真的发出去。

## 12. 常见问题

### 无法连接模型接口

检查：

- `base_url` 是否正确，是否包含 `/v1/chat/completions`。
- 办公电脑是否能访问该内网地址。
- API 是否需要 `api_key` 或额外 Header。
- 当前 `/model` 是否切到了错误 profile。

### 返回 401 或 403

**Web UI 版**：点设置 → 模型接口，里面就是密钥入口：

1. 「API-Key」填密钥（留空 = 不修改，点「清空密钥」才会删除），保存即写入 `config\agent.json`；
2. 点「测试连接」——它会真的向接口发一次 `GET /models`，把**实际用的地址、发出去的头、返回的错误**
   都打出来，并针对 401/402/429/404/405 给出中文原因，不用再猜；
3. 报 401（`Authentication Fails`）说明**密钥本身不对**（不是网络问题、不是模型名问题）。
   常见原因：密钥里有空格/换行、复制时少了几位、用的是别家网关的密钥、或者填到了"访问令牌"那一栏
   （那是保护 Web UI 自己的，不是模型密钥）；
4. 用企业网关时，密钥可能不是 `Authorization: Bearer`，而是 `api-key` 或自定义头 ——
   在「认证方式」里改，或选"自定义"自己填头名。

**EXE 版**：检查 `api_key` 是否正确、Header 名称和值是否正确、内网页面是否需要 Cookie 或 Basic Auth。

### 中文乱码

EXE 版内部使用 UTF-8。如果控制台仍然乱码，可以先执行：

```bat
chcp 65001
agent.exe chat
```

### 网页读取不到正文

可能原因：

- 页面由 JavaScript 动态加载。
- 没有登录态 Cookie。
- 页面禁止非浏览器客户端访问。

建议：

- 配置 Cookie/Header。
- 使用静态接口或导出页面。
- 手动保存为文本后用 `/file` 加载。

### 不想保留记忆

临时清空：

```text
> /clear
```

永久关闭：

```json
"memory": {
  "enabled": false
}
```

## 12.1 开机自启动（学校一体机）

这一版开机自启有**三条路一起走**：当前用户的注册表启动项（`HKCU\...\Run\Study7Agent`，
写的是**带引号的命令行 + `--autostart`**）、启动文件夹里的 `Study7Agent.lnk`、
以及程序每次启动自己校正路径。开机拉起来的那一份**只显示悬浮工具栏，不弹界面、不抢前台**。
（单文件版的 exe 叫 `study7agent-<版本>.exe`，自启认的是**正在跑的这一份的真实路径**，
升级换了文件名也会自动跟过去，不用重设。）

设法和修法只有两步：

1. 设置 → 「开机自动启动 Study7Agent」开关确认是**开**的；
2. 点旁边的 **「开机自启动诊断」** → 报告是红/黄就点 **「一键修复」**（重写启动项、重建快捷方式、
   清掉任务管理器里的禁用记录，并逐项回读确认）。用**老师平时登录的账号**做这两步。

诊断报告每一条读法、学校一体机最常见的五种失败原因（带空格目录的裸路径、C 盘还原卡、
管理员装/别的账号用、msconfig 被禁用、360/希沃管家拦截）、手动兜底办法，都写在
`docs\autostart-win7.md` 里。开机后**没看到界面是正常的**（自启档不弹界面），
点悬浮栏里的「显示界面」就有。

## 13. 升级和回退

升级：

1. 备份旧目录中的 `config\agent.json`、`skills\` 和需要保留的 `sessions\`。
2. 解压新版本。
3. 复制旧配置和自定义 skills。
4. 运行：

```bat
agent.exe version
agent.exe chat
```

回退：

1. 保留旧版本目录。
2. 如果新版本异常，直接切回旧目录运行。
3. 不需要卸载系统组件。
