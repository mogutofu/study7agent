# 各软件里那些功能在哪（老师最常问的几个）

写这份是因为"在别的窗口里找不到按钮"是老师最常抱怨的一条。**先按这份找，别去翻帮助。**

## 希沃白板 5（EasiNote5）
- 书写工具在**底部**那一条：笔（点一下可换粗细/颜色）、橡皮、选择、更多。
  **书写模式和选择模式要分清**：模式选错就会出现"写了没反应""点了没选中"。
- 「设置 / 账号 / 课件管理」一般在**左上角 logo** 或右上角头像、齿轮里。
- 翻页：底部中间的上一页/下一页，或 PageUp/PageDown；全屏播放用右下角按钮或 F5。
- 真坑：白板里写字必须按住拖才有笔迹（单击只会留一个点）：一笔用
  `move(drag=true, from_loc=[x,y], loc=[x,y])`，多笔用 `draw_path`（一次画完，比一笔一笔快很多）。

## 希沃展台（SeewoDisplay / SeewoVideo）
- 打开后一般自动出画面；顶部或右侧是「拍照 / 旋转 / 缩放 / 冻结」。
  **「冻结」是讲题时把当前画面定住用的**，不是暂停。
- 没画面先查摄像头和线，别在软件里反复点（软件里没有"重新连接"这种按钮）。

## WPS 演示 / PowerPoint
- **放映**：F5（从第一页）/ Shift+F5（从当前页）/ 右下角放映图标；**Esc 退出放映**。
- **设置**：「文件 → 选项」。放映相关的在「幻灯片放映」选项卡里（排练计时、自定义放映）。
- 翻页：PageUp/PageDown、方向键、空格；放映中右键有「指针选项」（当激光笔/画笔用）。
- 真坑：放映时是一个无边框全屏窗口，`snapshot` 里的标题可能只剩文件名；
  要回编辑状态按 **Esc**，别点右上角 ×（那是关文件，不是退出放映）。

## Edge / 360 浏览器（学校机器上就是这两个）
- **右上角 ⋯ / ⋮（三个点）或 ☰（三条杠）就是设置与更多**：新建窗口、历史、下载、打印、设置
  都在里面。360 的「工具」菜单里还有"切换到 IE 内核/极速内核"。
- **Ctrl+F 页内查找、Ctrl+L 到地址栏、F11 全屏、F5 刷新、Ctrl+T 新标签、Ctrl+W 关标签**。
- 缩放：Ctrl+加号/减号，或 Ctrl+滚轮；页面滚动用 `scroll(direction="down", wheel_times=3)`。
- 真坑：关标签用 Ctrl+W，别点窗口的 ×（那会关掉整个窗口）；
  标签点错了用 Ctrl+Shift+T 找回。

## 资源管理器（文件窗口）
- 「查看」里切图标/详细信息、排序、显示**文件扩展名**（改后缀前必须先打开它）。
- 新建文件夹：主页 → 新建文件夹，或 Ctrl+Shift+N。
- 找文件别一层层点：**地址栏直接粘完整路径回车**最快。

## 记事本 / 写字板 / Word
- 保存 Ctrl+S、另存为 Ctrl+Shift+S、撤销 Ctrl+Z、查找 Ctrl+F。
- 字体字号：记事本在「格式 → 字体」（新版在右上角齿轮）；Word 在「开始」选项卡。
- 真坑：写中文一律用 `type(text=...)`（走 Unicode 注入，不挑输入法），不要用 `shortcut` 逐字敲中文。

## Windows 通用
- **开始菜单**在屏幕左下角（Windows 徽标）；**托盘**在右下角时钟左边，
  点向上的小箭头展开隐藏图标（**QQ 收进托盘就在那儿**）。
- 开程序不用去点开始菜单：`app(mode="launch", name="计算器")` 按开始菜单里的显示名打开，
  知道完整路径就用 `app(mode="launch_executable", executable="C:\\...\\xx.exe")`。
- 切窗口/关窗口也别手点按钮：`app(mode="switch", name="窗口标题关键字")`、
  `app(mode="close", name=...)`；`clipboard` 走剪贴板。
- 左上角有三条杠（☰）的窗口，点它就是那个软件的主菜单。
- Alt+Tab 切窗口、Win+D 回桌面、Win+E 开资源管理器；Win+L 会锁屏，别乱按。
- 窗口的最小化/最大化/关闭在右上角三个按钮；任务栏图标点一下是切换、再点一下是最小化。
