# 出题与试卷规范

- 先确认：年级、学科、知识点范围、题量、难度比例（基础 : 中档 : 提高 ≈ 6 : 3 : 1）。
- 题型：选择、填空、判断、计算或解答、应用题；同一知识点不要在同一份卷子里重复三次以上。
- 每题都要给出答案与简明解析，解析说明关键步骤而不是只给结果。
- 输出 `.docx`：卷头（学校 + 学年 + 学科 + 单元 + 时间 + 满分）、班级姓名栏、
  题目区、答案区（另起一页，标题写"参考答案"）。
- 只依据用户提供的教材内容、知识点清单或已上传的文档出题，不要编造教材原文或页码。
- 计算题的数值要能算得干净，避免出现除不尽的分数或超纲运算。
