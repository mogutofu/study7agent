# 希沃白板快速作图 Skill

老师在教室一体机上要求「打开希沃白板画一个 XX」时用这套流程。**核心是提速**：
一次调用只做一件事会被嫌弃慢，**能合并到同一轮的工具调用就合并**（实测同一轮里按顺序执行）。

## 一、先看屏幕，别指望窗口表

- `snapshot` 的**窗口表**（`app` 的窗口信息也一样）**永远枚举不到希沃白板窗口**（标题为空），即使它正全屏可见。
  **不要靠它判断白板在不在**。
- 直接用 `screenshot` 看：分辨白板是否在前台、当前第几页、工具栏在哪。
- 白板常驻进程：`EasiNote.exe` 有 4 个实例 + `EasiNote.Cloud.exe`。
  **重启 exe 不会新开页面、也不省事**（进程数不变），不要靠 `start EasiNote.exe` 来"打开白板"。
- 白板最小化/被其他窗口压住时：点任务栏那个**绿色「EN」图标 ≈ (370,1043)** 唤到前台（点错任务栏按钮只切焦点，风险低，可直接试）。

- 画坏了：点撤销 (959,1040)，一次撤一笔。

## 三、两轮搞定（推荐节奏）

**第 1 轮（一个 block 里发 3 个调用）**：`click 加页` → `click 笔` → `screenshot`
**第 2 轮（一个 block 里发 2 个调用）**：`write_file 画图脚本` → `run_command 跑脚本`
**第 3 轮**：`screenshot` 验收（+ 顺手清理临时截图）

- 如果老师要的图是画在**新页**上，先加页，别覆盖上一页的板书（加完页记下页码，如 17/17）。
- 同一轮里的调用是**按顺序执行**的（click→capture 能拍到点击后的状态），放心合并。
- 想再快：色板若不需要改笔粗细/颜色，就**跳过选笔粗细那步**（默认笔已经是可用状态）。
- 验收完删临时截图：`del` 属高危前缀**会弹确认框，请老师点一下**；多条 `del` 合并成一条命令只弹一次。

## 四、画图脚本（唯一正确姿势：所有笔画写进一个脚本，跑一次）

本机 python 硬性注意：
- **必须带 `< nul` 重定向**，否则报 `can't initialize sys standard streams`：
  `cd /d <脚本目录> && python draw_xxx.py < nul`
- **没装 PIL**，不能裁图；要看细节就重新截屏。
- 脚本里**只用 ASCII**（脚本名、注释都无所谓中文，但避免命令行里传中文参数）。

```python
# -*- coding: utf-8 -*-
import ctypes, math, time
u = ctypes.windll.user32
LD, LU = 2, 4                     # mouse_event 左键按下 / 抬起

def stroke(pts, dwell=0.012):     # 按下 → 沿点列移动 → 抬起 = 一笔
    u.SetCursorPos(int(pts[0][0]), int(pts[0][1])); time.sleep(0.05)
    u.mouse_event(LD, 0, 0, 0, 0); time.sleep(0.05)
    for x, y in pts[1:]:
        u.SetCursorPos(int(round(x)), int(round(y))); time.sleep(dwell)
    time.sleep(0.06)
    u.mouse_event(LU, 0, 0, 0, 0); time.sleep(0.05)

OX, OY, U = 960, 540, 170         # 原点 + 一个单位的像素数
strokes = [
    [(OX-500, OY), (OX+495, OY)],                  # x 轴（直线只写 2 个点，一次跳到位）
    [(OX+500, OY), (OX+462, OY-28)],               # 箭头一撇
    [(OX+500, OY), (OX+462, OY+28)],               # 箭头另一撇
    [(OX, OY+375), (OX, OY-382)],                  # y 轴
    [(OX, OY-388), (OX-28, OY-350)],
    [(OX, OY-388), (OX+28, OY-350)],
    # 椭圆 x²/4 + y²/1 = 1：一笔连续画完，72 点够圆滑
    [(OX + 2*U*math.cos(2*math.pi*i/72), OY + 1*U*math.sin(2*math.pi*i/72)) for i in range(73)],
]
for s in strokes:
    stroke(s)
```

经验数值：
- **直线只给首尾两点**（瞬间跳过去反而最直），箭头、刻度同理；只有曲线才需要密点。
- 刻度：短线各 14px（`(x, OY-14)→(x, OY+14)`）；箭头：两撇各约 28px。
- 耗时参考：坐标系（6 笔）+ 8 个刻度 + 一个椭圆 = 15 笔，**4.8 秒**。别一次只画一条线就 return。
- 圆/椭圆/抛物线等：一律参数方程生成点列，别画多边形近似。
- 已写好的可复用脚本：`C:\Users\seewo\Desktop\bench\bench\tools\draw_coord.py`（坐标系+椭圆）、`draw_cube.py`（正方体），改 `OX/OY/U` 即可平移缩放。

## 五、验收与收尾

- **必须 screenshot 验收**：只看 exit=0 会误判（白板没拿到焦点时脚本照样 exit=0，画布上什么都没有）。
- 文件大小可做粗判：深色画布空白页约 23KB，画了图约 45KB。
- 成品截图改名归档到 `截图\` 目录（如 `coord_result.png`），过程截图（找窗口那几张）删掉，别留在老师工作区。
- 中文相对路径可以直接用在 `del` / `move` 里，**不要加引号**；引号才是 Win7 上的坑（见 `win7-file-open` skill）。

## 六、还能更快的地方 / 已知较慢的操作

- **文字标注（x、y、O、方程标签）慢**：得走「更多」→ 文本 → 点画布 → 输入，一个标签一次操作。
  默认**先问老师要不要加**，或者等图形画完主动提一句"要不要加 x、y、O 标注"，别一声不响地花 4 轮去插文本框。
- 画完可以顺手把图形要点用 `show_on_screen` 投屏（图形在画布上、要点在大屏上），比在白板里写字快得多。
