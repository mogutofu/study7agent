# 翻译与查词

## 翻译四步（顺序别换）

1. **定场景**：这段是课文、通知、说明书还是学术材料？场景决定用词（课文贴原文、
   通知要短句、说明书要术语一致）。
2. **定术语**：同一份材料里同一个词只能有一种译法。第一次出现写"术语（原文）"，
   后面一律统一；拿不准的术语**保留原文并给候选译法**，不要硬翻。
3. **断句**：英文长句先拆出主谓宾骨架再翻；中文长句先找出几个动作再合并。
4. **回读**：通读一遍，删掉"的的不休"和多余的"进行""使得"。

## 输出格式

- **双语对照**：一段原文 + 一段译文交替排列。**只给中文是没用的**——老师要对着原文改。
- 整篇材料最后附一张**术语表**：原文 → 译文 → 出现次数。
- 下面这些内容**原样保留、不翻译**：数字、单位、公式、代码、网址、邮箱、
  人名地名机构名、书名号里的作品名。

## 查词输出模板（一个词一段）

```
apple  /ˈæpl/  n.  苹果
本文义：苹果（课文第 2 段，指水果）
其他常见义：Apple 苹果公司（专有名词，首字母大写）
例句：An apple a day keeps the doctor away.
易混：apple（苹果）/ apply（申请、应用）
```

- 一词多义时给 **2 个常见义项**并标出**本文用的是哪个**，不要罗列词典全部义项。
- 老师要生词表时，输出"单词 / 音标 / 词性 / 中文 / 例句"五列，存成 `.csv`，
  可以打印，也可以导入记忆软件（见 `flashcards`）。

## 长难句拆解

1. 先断句，标出**主句的主语和谓语**；
2. 再逐层挂从句，写清每层修饰的是谁（"which 修饰的是前面的 the book，不是整个句子"）；
3. 最后给一版**贴原文的直译**和一版**像中文的意译**，并说明哪里为了通顺调了语序。

## 语气调整

- 中译英：教学材料以课标词汇为主，避免生僻词，不用营销腔。
- 英译中：给学生看的译文要短句、口语化；给老师看的译文可以保留学科术语。
- 改错 / 润色时**逐条列出改了什么、为什么改**，不要直接甩一版新的让学生看不出差别。

## 不要做

- 不要为了通顺改掉原文的事实、数量或否定词（漏掉 not、少个零，是最严重的错）。
- 不要在同一份材料里前后换译法。
- 不确定的地方**明说"这里不确定"**，不要猜一个看起来合理的译法。
