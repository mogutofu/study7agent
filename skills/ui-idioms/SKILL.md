# 在别人的窗口里找功能（常驻规矩）

老师原话："感觉 ai 在别的窗口操作的时候比较蠢，比如完全不知道三条杠代表设置，
想要找帮助文档浪费时间。" 这份就是给这件事定的规矩：**按顺序找、最多两轮、不翻帮助。**

## 1. 先找界面上的中文字（最快、最准）
写着「设置 / 选项 / 属性 / 首选项 / 偏好 / 更多 / 管理」的按钮或菜单项，就是它。
用 `snapshot(find="设置")` 按**文字**找控件（中文界面就搜中文），比认图标可靠得多——
命中会直接给你 `[编号]`，`click(label=N)` 就能点它（坐标按当前界面重算）。
`find` 没命中再用 `snapshot` 看整屏清单，最后才 `screenshot` 看图对坐标。

## 2. 图标含义（几乎所有软件都一致）
| 看到什么 | 它是什么、该不该点 |
| --- | --- |
| ☰ 三条横杠（左上角） | 主菜单。桌面软件的「设置」十有八九在里面 |
| ⋮ 竖着三个点 / ⋯ 横着三个点 | 更多操作（当前列表、卡片、文件上的） |
| ⚙ 齿轮 / 滑块 | 设置。有齿轮就直接点，不用再找菜单 |
| 头像 / 人名 / 首字母圆圈 | 账号菜单，「设置、切换账号、退出」常在里面 |
| 🔍 放大镜 | 搜索 |
| × / 「关闭」 | 关掉**当前面板**（不是退出软件；要退出去文件菜单或托盘图标右键） |
| ⟳ / 「刷新」 | 重新加载 |
| 左上角 logo / 「首页」 | 回主界面 |
| 右下角三角 / 「^」 | 收起或展开面板（不是删除） |

## 3. 找不到就按这个顺序试，每步只试一次
1. **右键**：Windows 软件里，画布、幻灯片、图片、表格单元格、文件列表的右键菜单
   是最容易翻出隐藏功能的地方。先右键看一眼。
2. **左上角三条杠 / 齿轮 / 头像**（见上表）。
3. **菜单栏**：传统软件在「工具 → 选项」或「文件 → 选项」；WPS/Office 在「文件 → 选项」。
   菜单栏被藏起来了，按一下 **Alt** 就出来。
4. **快捷键**（比点菜单快，也不怕界面改版，还不用动鼠标）：用 `shortcut`——
   `ctrl+s` 保存、`ctrl+z` 撤销、`ctrl+f` 查找、`ctrl+p` 打印、`ctrl+a` 全选、
   `f5` 放映/刷新、`f11` 全屏、`esc` 关弹窗或退出全屏、`tab` 下一个、`enter` 默认按钮、
   `alt+tab` 切窗口、`win+d` 回桌面。
5. 还没有 → **用一句话问老师**："这个软件的××在哪？" 老师一句话，比你翻三分钟强。

## 4. 明确不要做的（这些最费轮次）
- **不点「帮助」、不读软件自带教程、不在浏览器里搜"××怎么设置"再读长文**：
  平均要 5–8 次调用才能翻到答案，还经常翻到旧版本界面。
  **"找功能"的预算就是两轮**；两轮没有就换第 3 步的下一招，或者直接问老师。
- 不要为了找一个选项把整个菜单挨个点开（那叫翻，不叫找）。
- 同一个没反应的按钮最多点两次；第二次还不灵就说明找错地方了，换方法。
- 不要用像素坐标猜按钮位置：先按文字找（`snapshot(find=...)`），找不到再看图核对坐标。
- 不要连续快速点（老师正在用这台电脑，点飞了会点到别处；这一版的点击是**真鼠标**）。
