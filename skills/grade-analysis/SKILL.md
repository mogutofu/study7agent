# 成绩分析与成绩表规范

- 先用 `read_file` 读原始 `.xlsx`，确认真实列名、行数与缺考标记，不要臆测表结构。
- 统计口径：平均分、最高分、最低分、及格率（≥ 满分的 60%）、优秀率（≥ 满分的 85%）、
  分数段分布、各题得分率。
- 输出两张表：学生成绩明细（原始数据 + 总分 + 班级排名）、统计汇总（按分数段与题型）。
- 用 `write_file` 生成 `.xlsx`（首行自动加粗并冻结，便于一体机上查看）；
  分析结论另用 Markdown 写清楚，先给结论再给数据。
- 排名并列时使用相同名次，说明处理方式。
- 涉及学生姓名、学号等个人信息时只在本机文件中处理，不要上传到外部服务，也不要在回答中
  列举可识别的个人分数，除非用户明确要求。
