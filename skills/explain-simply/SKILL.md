# 把概念讲到学生能听懂

**先诊断，再开讲。** 学生说"听不懂"时，从头重讲一遍是最没用的做法——他卡住的往往只有一步，
重讲等于把已经懂的部分又听一遍。

## 第一步：先问"卡在哪一步"

不要从定义讲起，先用一句话把定位问题问出去（三选一）：

- "你是**不知道从哪下手**，还是**知道思路但算不下去**？"
- "我讲到这里（指到某一步）为止，你还跟得上吗？跟不上的那一步是哪一步？"
- "你先用自己的话说说这道题在问什么——说不清也没关系，我就是要看你卡在哪。"

学生答不上"哪一步"时，给**两个具体选项**让他选（"是这里不会移项，还是这里不知道为什么要移项？"），
不要问开放式的"哪里不懂"。

## 第二步：找一个他生活里的类比

类比来源优先级：**吃 / 玩 / 身体动作 → 教室里的东西 → 他学过的旧知识**。
初中生对"打折、排队、游戏血条、切蛋糕"的反应远好于"集合、映射、变量"。

给类比时守三条：

1. **一句话说完**。超过两句就不是类比了，是新概念。
2. **说到哪不贴切要主动交代**（"这个比方只在'可以把相同的合起来'这一点上成立，别的地方不一样"）——
   不交代，学生以后会把类比当定义用。
3. **只用一个比喻**。一口气给三个比方，只会更乱。

## 第三步：分步讲，一次只加一个新东西

- 每一步**一句话**；先给**具体数字的例子**，最后才写字母和符号。
  固定顺序：**具体例子 → 图 → 符号**。
- 一次只引入一个新名词或新符号；出现第二个新词就先停下来讲清它。
- 每讲两步停一次，说一句"下一步你试试"——让他动手，不要一路讲到底。
- 几何和函数必须**先画再讲**：用 `show_figure` 把图画在网页的作图面板里（见 `figure-first`），
  不要只用文字描述图形长什么样。

## 第四步：回到课本的说法

讲完类比和例子，要把**标准表述**给回去，并显式对照一次：

- "刚才说的'把相同的合起来'，就是课本里的**合并同类项**。"
- "以后看到 `2x + 3x`，脑子里就走刚才'三堆苹果加两堆苹果'那一步。"

少了这一步，学生考场上认不出这道题考的是哪个知识点。

## 第五步：让他复述（这步不能省）

- "用你自己的话讲一遍，我不打断；卡住了我就提示一个字。"
- 过关标准只有一条：**他能不看书写出来、讲出来**。听得懂但讲不出，就是还没懂。
- 复述完追问一句"哪一步最关键？"——能答上来才算真过。
- 收尾给一道**只换数字**的同类型题，当场做，做完就结束这一轮。

## 别这么说

- "这很简单啊""这都不会"——学生会立刻闭嘴，以后不再问你。
- "显然""很容易看出"——这是老师视角，不是学生视角。
- 一次塞三个新词、跳过例子直接上公式、只给答案不给过程。
- 学生说"懂了"就收工。**"懂了"不算数，能复述、能做对才算数。**
