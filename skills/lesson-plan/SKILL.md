# 教案写作规范

- 用 `write_file` 生成 `.docx`：支持 `# 标题`、`- 列表`、`| 表格 |`、`**加粗**`。
- 固定栏目顺序：课题 / 课时 / 授课对象 → 教学目标 → 教学重点与难点 → 教学准备 →
  教学过程 → 板书设计 → 作业布置 → 教学反思（留空待填）。
- 教学目标按三个维度写，用可观察的行为动词（能说出、能计算、能比较、能举例），
  不要写"理解""掌握"这类无法检验的表述。
- 教学过程用表格呈现：环节 | 时间 | 教师活动 | 学生活动 | 设计意图。
  环节时间之和必须等于课时长度（小学 40 分钟、中学 45 分钟）。
- 重难点要与教学目标对应，不要重复罗列知识点。
