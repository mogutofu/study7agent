# 成绩与学情报告

**边界**：分数段、及格率、优秀率这些统计口径与成绩表整理 → `grade-analysis`；
具体错题归因与补救顺序 → `error-analysis`；写给家长的一段话 → `parent-report`。
这份技能管的是**一份正式的书面报告怎么写**。

## 第一步：先把口径写清楚（不写口径的数据不能进报告）

报告开头一行必须交代：**数据来源**（哪次考试、哪个班、多少人）、**缺考或未交怎么处理**、
**满分与及格线、优秀线**。这三样不写，看报告的人会各自理解成不同的东西。

- 所有统计**必须用 `score_stats` 算**（平均分、中位数、标准差、及格率、优秀率、分数段），
  不允许心算和估算。
- 与上次对比必须**同口径**（同一个班、同一种难度）；卷子难度不同就写明
  "本次卷面难度高于上次，不直接比平均分"，只比知识点得分率。

## 第二步：固定结构（结论前置）

1. **一句话结论**：本次最值得注意的一件事（"整体持平，但分式运算得分率从 72% 掉到 51%"）。
2. **数据**：平均分 / 及格率 / 优秀率 / 分数段分布，用表格，不超过 5 行。
3. **与上次对比**：只写变化最大的 2 项，不要罗列全部。
4. **典型错因**：取 `mistake_book(action="stats")` 的前 3 个知识点，每个配一句学生的典型错误
   （"去分母时漏乘不含分母的项"）。
5. **下一步措施**：分三列写清 **教师做什么 / 学生做什么 / 需要家长配合什么**；
   每条都要落到具体动作和时间（"下周每天课前 5 分钟练 3 道通分"）。
6. **需要协调的事**：缺课时、缺练习册、需要教研组统一进度等；没有就写"无"。

## 第三步：诚实性与隐私

- **不编造指标**：缺的数据写"待补充"，并说明需要什么数据、从哪里取；
  样本少于 10 人要注明"样本小，仅供参考"。
- 默认**不列学生个人分数**，只给统计结果；确实需要点名（小范围教研）时先确认对象范围，
  并在报告里注明"含个人信息，仅限内部使用"。
- 说不清的因果关系写"可能相关"，不写"因为……所以……"。

## 第四步：输出

- 正式报告用 `write_file` 生成 `.docx`：标题带学校 / 学年 / 班级 / 考试名称 / 日期。
- 要投屏的摘要另出一份**一屏不超过 5 行**的要点（`show_on_screen(kind="points")`），
  大屏上不出现学生姓名。
- 表格列数不超过 5 列，数字保留 1 位小数；百分比同时给人数（"及格率 82%（41/50）"）。
