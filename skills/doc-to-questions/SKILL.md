# 把课件 / 文档变成随堂问题链

**边界**：要成卷、要排版、要评分标准的笔试题 → 走 `quiz`。
这里做的是**课堂上口头问的问题**：一页课件出 6-8 问，能直接投屏用。

## 第一步：先把文档读进来

- 用 `read_file` 读老师给的课件、教材页或文档；**只用文档里真实出现的内容**，
  不要编造页码、例题编号和教材原文。
- 先找出这一页的**一个核心结论**（学生下课必须记住的那句话），所有问题都围着它转。

## 第二步：按三层出题（6-8 问）

| 层次 | 题量 | 问法特征 | 例子 |
| --- | --- | --- | --- |
| 记忆 | 2 问 | 能说出、能指出、能复述 | "光合作用的原料有哪两样？" |
| 理解 | 2-3 问 | 能解释、能比较、能用自己的话说 | "为什么必须有光？没有光会怎样？" |
| 应用 | 2 问 | 能算、能举例、能迁移到新情境 | "把这盆植物放进黑箱子三天，叶子会怎么样？" |

**只出记忆题等于白问**；一上来就出应用题，学生答不上来、课堂冷场。
顺序固定：记忆 → 理解 → 应用。

## 第三步：问题链要有依赖，不要平行罗列

好的问题链是"上一问的答案是下一问的台阶"：

```
这页讲了什么？（记忆）
→ 为什么要这么做？（理解）
→ 不这么做会怎样？（理解·换视角）
→ 如果条件换成……你还会这么做吗？（应用）
```

每一问后面跟一行**期待的答案要点**（不是完整答案），你才知道学生答到什么程度算过关。

## 第四步：每个问题配三样东西

写问题时按这个格式，一问一段：

```
问：……？
要点：……（学生说到这几个词就算过）
方式：全班齐答 / 抽学号 / 同桌互说 30 秒
时间：想 5 秒
```

- **全班齐答**：热身、确认"都听清了"时用；答案只有一个词时最合适。
- **抽学号**：想清楚再抽，用 `pick_students`；投屏只显示"请回答：学号 12"。
- **同桌互说**：理解层和开放性问题用；30 秒后抽一组说结论。
- 提问后**等 3-5 秒**再点人（"想 10 秒我再抽"）；没人应声就降级成二选一。

## 好问题的检查表

- [ ] 只有一个问号，不带"对不对""是不是"这种暗示答案的尾巴
- [ ] 不需要猜老师心里想的是哪个词
- [ ] 答错也能接着追问（"你是怎么想的？"接得上）
- [ ] 能用学生自己的话说出来，不要求背原句
- [ ] 有明确的答案要点，你自己知道什么算过关

## 第五步：课堂怎么用

- 投屏一次一屏：`show_on_screen(kind="question")` 投问题，需要时再投 `answer` 显示要点；
  一节课的节奏与工具用法见 `classroom`。
- 需要限时思考就 `class_timer(seconds=60, label="独立思考")`。
- 下课前把"学生答不上来的那两问"记下来——那就是下节课的复习点，也是作业的重点。
