# 在 QQ 里打开图片：双击的是「图片」，不是「消息」

老师原话：**"双击图片位置而不是消息。"**

在 QQ 聊天记录里打开一张图片，唯一有效的动作是：**把鼠标双击在图片缩略图的图像区域上**。
双击消息的文字部分或气泡空白处，QQ 会把它当成"引用回复"，图片不会打开。

## 怎么做

1. **先确认现场**：`snapshot` 看 QQ 在不在前台、窗口在哪（窗口清单就在快照文字里）；
   再看那张画面核对聊天记录的位置。
2. **找到最新那张图**：消息是从上往下、越往下越新。在消息区中间用
   `scroll(direction="down", wheel_times=5)` 滚到底，看最新一条带图的消息。
3. **认准图片本身**：一条"文字 + 图片"的消息里，文字在气泡左侧、图片缩略图在右侧
   （一块有画面的矩形区域）。**取这块画面区域的中心点**，不要把点落在文字上。
4. **双击它**：`click(loc=[x, y], clicks=2)`（就是双击）落在图片中心。
5. **验证**：`screenshot` 确认图片查看器（大图窗口）真的打开了。

## 不要做什么

- **不要双击消息文字区 / 气泡空白处**：那会触发「引用回复」——
  输入框上方冒出引用卡片（"某某: 消息内容" 加一个 @某人），图片照样没打开。
  这一步踩过，白花好几轮。
- **不要先单击图片试水**：实测单击图片缩略图不会打开查看器，还可能把消息选中，浪费一轮。
- **不要改成右键翻菜单**：不用去菜单里找"查看原图"，直接双击图片是最快的路。
- **坐标没把握就不要连点**：先重新 `screenshot` 核对图片位置，再点一次，
  避免点到别的消息或按钮上（坐标是屏幕物理像素，窗口一动就作废）。

## 真要走右键菜单（例如"另存为"）：只按文字点，绝不按坐标猜

老师原话："尝试右键打开图片会莫名其妙点击精华消息。" —— 群聊的消息右键菜单里
**第一屏就有「精华消息」**，按坐标点菜单项极容易点成它：那是**有副作用**的操作，
会把一条消息设成精华，老师还得手动取消。

所以右键菜单只有一种正确操作顺序：

1. 右键**图片缩略图的画面区域**（不是气泡、不是文字）：`click(loc=[x, y], button="right")`。
2. **先看清菜单里到底有哪些项**：`snapshot(find="另存为")`（或 `snapshot(read_text=true)`）
   列出弹出来的菜单项和它们的 `[编号]`。
3. 用 **`click(label=N)`** 点那一项——按文字找到的控件，坐标由程序按当前界面重算，
   比手抄像素稳（注意：它**仍然会真的移动鼠标**，只是不会点错地方）。
4. 菜单里没有那一项就 `shortcut("esc")` 关掉重来 ——
   **宁可不做，也别点「精华消息 / 撤回 / 删除」这类带副作用的项**。

通用规矩：**菜单项一律按文字点，不按位置猜**；凡是有"撤回 / 删除 / 精华 / 置顶 / 全员禁言"
这种会改群状态的项，点之前必须确认标题就是你要的那一个。

## 双击了却出现引用卡片，怎么收场

1. 说明点到消息文字了 —— **千万不要按发送**，那会把一条空回复（带引用）发到群里。
2. 清掉引用：点引用卡片上的 ×（或点输入框外面让它失效）。
   **这台机器上按 Esc 会让 QQ 主窗口从桌面上消失**（要重新打开 QQ），所以别用 Esc。
3. 重新 `screenshot`，把坐标往图片**中心**挪一点，再双击一次。
