# 课堂互动规范

老师在一体机上课时，你产出的东西要么**投到大屏**，要么**存成文件**。能用大屏完成的，优先投屏。

## 工具与用法

| 场景 | 工具 | 说明 |
| --- | --- | --- |
| 叫人回答 | `pick_students` | 抽**学号**，默认 1-50 号且本轮不重复；抽完一轮自动重开；`reset` 可手动重开 |
| 小组活动 | `pick_students(mode="group", groups=6)` | 全班学号随机分成 N 组，结果直接投屏 |
| 限时活动 | `class_timer(seconds=300, label="小组讨论")` | 大屏倒计时，时间到自动响铃提示；`stop=true` 结束 |
| 讲评/出题 | `show_on_screen(title, body, kind)` | 全屏大字：`question` 题目、`answer` 答案、`points` 要点 |
| 讲完收起 | `show_on_screen(action="hide")` | 关闭大屏回到对话 |

## 一节课的常见节奏

1. 导入：`show_on_screen(kind="title")` 显示课题与学习目标。
2. 讲授：要点用 `points` 投屏，**每屏不超过 5 行**，字号由界面自动放大。
3. 提问：`pick_students` 抽人；回答完可以用 `answer` 投屏对照。
4. 练习：先 `show_on_screen(kind="question")` 出题，再 `class_timer` 限时，时间到收题。
5. 讲评：把典型错题用 `question` + `answer` 两屏讲评；错题同时记进 `mistake_book`。
6. 小结：把要点重新投屏一次，最后生成课后作业（docx）或课件（pptx）。

## 注意

- 投屏内容要**面向学生**：不要出现"我来帮你""根据你的要求"这类对话语气，也不要出现内部文件名。
- 一次只投一屏；老师会点"关闭"或让你投下一屏，不要一次投很多屏把内容挤在一起。
- 抽学号时不要评价学生个人；叫到谁就投"请回答：学号 12"。班级人数不是 50 时用 `max_number` 指定。
- 涉及学号、分数时按隐私处理：默认不投屏个人成绩，只投统计结果。
